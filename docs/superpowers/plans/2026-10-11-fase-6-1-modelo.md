# SGSPE · Fase 6, plan 6.1 (modelo y GeoServer): plan de implementación

> **Para agentes:** SUB-SKILL OBLIGATORIA: usar superpowers:subagent-driven-development (recomendada) o
> superpowers:executing-plans para ejecutar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`) para el
> seguimiento. Cada tarea de código sigue superpowers:test-driven-development: prueba que falla, implementación mínima,
> prueba en verde, commit.

**Goal:** Dejar en `~/IdeaProjects/sgspe` el modelo de F6 («SIG avanzado») aprovisionable de punta a punta —`code` y los
campos de origen en `community` y `environmental_feature`, la acción `EXPORT` en los trece objetos de las capas
territoriales y sus concesiones en `roles.json`—, las capas públicas de GeoServer como datos (`model/layers.json`, un SLD
por capa y la paleta), `model/publish_layers.py` con sus pruebas contra un core y un GeoServer de imitación, el paso de
las capas en el alta y la subida de fase de los tenants, GeoServer en el compose con su configuración, y la base de
pruebas `F6ApiTest` que usan los planes 6.2a y 6.2b.

**Architecture:** El modelo sigue siendo datos en `model/` aplicados por REST con Python de solo biblioteca estándar
(ADR-0007). `design_docs.py` aprende a leer la fase de una acción declarada, los maestros del tenant de `security.md`
§9.7 y las capas públicas de `gis.md` §2.2, y `test_model.py` exige con eso que `layers.json` solo nombre maestros de
`ProjectScope.TENANT` sin campos restringidos. `publish_layers.py` valida la lista sin red, publica por core (`POST
/api/gis/layers/{objeto}/{geometría}`, como el administrador del tenant) y carga los SLD globales por la API REST de
GeoServer con credenciales que llegan solo por variables de entorno. Del Kotlin, este plan toca solo la configuración de
GeoServer (`application*.yml` y `ProdProfileTest`), una regla de `ArchitectureTest`, `build.gradle.kts` y las pruebas
(`F6ApiTest`, `SyntheticGeoTest`, `TerritoryModelApiTest`, `TenantProvisioningApiTest`).

**Tech Stack:** Kotlin 2.4.20, Spring Boot 4.1.1 (WebFlux con corrutinas), JDK 25, Gradle 9.8.0, `wasichai-bom` 1.0.0
(sin starters nuevos); JUnit 5 con `wasichai-test`; PostgreSQL 18 con PostGIS 3.6; GeoServer `docker.osgeo.org/geoserver:3.0.1`
(SLD 1.0.0); Python 3.11 o superior (solo biblioteca estándar: `urllib`, `http.server`, `xml.etree`).

**Spec:** `docs/superpowers/specs/2026-10-11-fase-6-design.md` (vinculante): restricciones globales, §2.1 (decisiones 1,
3 y 4), §2.2 (elecciones 1 y 2), §3.3 («Despliegue en desarrollo», «Publicación», «Estilos»), §3.4 («Destinos nuevos»,
solo el modelo), §3.5 (objetos de las exportaciones, solo el modelo y los permisos), §4 (entero), §5 (filas «Modelo» y
base `F6ApiTest`), §7 (fila 6.1, «Tareas del coordinador», «Orden de despliegue») y §8 (riesgos 4 y 6). El contrato común
de los planes de F6 (`F6ApiTest` y sus ayudas, reglas del entorno) fija los nombres que este plan crea. Los documentos
como los deja el plan 6.0 (`docs/superpowers/plans/2026-10-11-fase-6-0-documentos.md`). Lo que la especificación asigna a
6.2a (`SpatialGate`, consultas, KPI-TER), a 6.2b (proxy WMS, mapa base, GDAL, destinos nuevos de la importación,
exportaciones, calidad) y a 6.3 (portal, copia de la paleta) queda fuera.

## Review Focus

Las cinco entradas que la especificación implica y que más pueden morder a quien use esto, cada una con su prueba en la
tarea dueña del código:

1. **Subir el tenant `demo` (que ya tiene datos) de F5 a F6.** Se espera que `apply.py` agregue solo los ocho campos y
   las trece acciones, que el único de `community.code` entre sobre una tabla con filas (todas con `code` nulo, que
   PostgreSQL no compara) y que una segunda corrida no escriba. Pruebas:
   `test_a_tenant_of_f5_moves_to_f6_adding_only_its_fields_and_export` (Tarea 2) y, contra wasichai de verdad,
   `TerritoryModelApiTest` «sin código, las comunidades no chocan» (Tarea 8) y la subida real del coordinador (Tarea 9).
2. **Volver a correr `publish_layers.py`** (otro tenant del mismo despliegue, otra subida de fase, un GeoServer que
   reescribe el SLD al guardarlo). Se espera que no publique dos veces ni reemplace un estilo igual. Pruebas:
   `test_una_segunda_corrida_no_escribe` y `test_un_estilo_distinto_se_actualiza_y_uno_igual_con_otro_formato_no`
   (Tarea 5).
3. **Alguien agrega a `layers.json` una capa de proyecto o con datos personales** (LYR-13, LYR-14). Se espera que nada
   llegue a GeoServer: `publish_layers.py` sale con 2 antes de llamar a nadie, y `test_model.py` y `ArchitectureTest`
   fallan. Pruebas: `test_un_objeto_de_proyecto_no_se_publica`, `test_un_objeto_con_campos_restringidos_no_se_publica`,
   `test_un_layers_json_invalido_sale_con_2_sin_llamar` (Tarea 5), `PublicLayersTests` (Tarea 4) y `ArchitectureTest`
   «las capas que publica GeoServer son maestros del tenant sin campos restringidos» (Tarea 4).
4. **Las credenciales de GeoServer.** Se espera que solo lleguen por el entorno, que sin ellas el script salga con 2 sin
   tocar core ni GeoServer, que nunca salgan en la salida (tampoco con un 401) y que el alta de un tenant en un despliegue
   sin GeoServer pueda omitir el paso. Pruebas: `test_las_credenciales_de_geoserver_llegan_solo_por_el_entorno_y_no_salen`
   (Tarea 5), `test_sin_geoserver_se_omite_solo_la_publicacion_de_las_capas` (Tarea 6) y `ProdProfileTest` «GeoServer no
   hereda credenciales ni hosts de desarrollo» (Tarea 7).
5. **Core sin GeoServer o un tenant sin el modelo.** `WASICHAI_GIS_GEOSERVER_ENABLED=false`, GeoServer caído o una
   geometría que el tenant no tiene: se espera salida 1 que nombra la capa o pide correr `apply.py`, sin publicar a medias
   ni cargar estilos. Pruebas: `test_core_sin_geoserver_falla_nombrando_la_capa`,
   `test_un_tenant_sin_la_geometria_falla_antes_de_publicar` y `test_geoserver_caido_falla_sin_traza` (Tarea 5).

    """La línea del "name" del objeto y la de su cierre."""
    start = lines.index(f'      "name": "{name}",')

    """El campo como lo escribe model.json: las claves en su orden, la descripción de la ficha sin comillas invertidas."""
    e = {"name": field["name"], "label": LABELS[field["name"]], "type": field["type"]}

    if field["required"]:
        e["required"] = True
    if field["unique"]:
        e["unique"] = True
    if field["name"] in card.indexed:
        e["indexed"] = True
    e["description"] = field["description"].replace("`", "")
    return "        " + json.dumps(e, ensure_ascii=False)

    card = cards[name]
    start, _ = span(name)
    first = lines.index('      "fields": [', start)

    present = {}
    for line in lines[first + 1:last]:

        present[json.loads(text)["name"]] = "        " + text
    block = []
    for field in card.fields:

            block.append(present[field["name"]])
        elif design_docs.field_phase(card, field) == "F6":
            block.append(entry(card, field))
        else:
            raise SystemExit(f"{name}.{field['name']} falta en model.json y no es de F6")
    lines[first + 1:last] = [line + "," for line in block[:-1]] + [block[-1]]

            out.append('      "permisos": {')
            for j, (obj, actions) in enumerate(items):
                out.append(f"        {json.dumps(obj)}: {json.dumps(actions)}" + ("," if j < len(items) - 1 else ""))
            out.append("      }")
        else:

        out.append("    }" + ("," if i < len(data["roles"]) - 1 else ""))
    out.append("  ],")
    out.append('  "restrictedFields": [')

`model/fake_geoserver.py`:

```python
"""Un GeoServer de imitación para test_publish_layers.py: la API REST de estilos globales (GET .sld, POST con ?name= y PUT)
con autenticación básica, en memoria, como responde GeoServer: 401 con otras credenciales, 404 si el estilo no existe y
403 si el alta repite un nombre. Solo para las pruebas."""
import base64
import re
import threading
import urllib.parse
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

STYLES = "/geoserver/rest/styles"
STYLE = re.compile(r"^/geoserver/rest/styles/([A-Za-z0-9_.-]+?)(\.sld)?$")
SLD_TYPE = "application/vnd.ogc.sld+xml"


class FakeGeoServerHandler(BaseHTTPRequestHandler):
    def log_message(self, *args):
        pass  # keep test output quiet

    def _handle(self, method):
        length = int(self.headers.get("Content-Length", 0))
        body = self.rfile.read(length).decode("utf-8") if length else None
        authorization, content_type = self.headers.get("Authorization"), self.headers.get("Content-Type")
        with self.server.lock:
            self.server.requests.append((method, self.path, authorization, content_type, body))
            status, text = self.server.script(method, self.path, authorization, content_type, body)
        self.send_response(status)
        self.send_header("Content-Type", SLD_TYPE if method == "GET" and status == 200 else "text/plain")
        self.end_headers()
        if text:
            self.wfile.write(text.encode("utf-8"))

    def do_GET(self):
        self._handle("GET")

    def do_POST(self):
        self._handle("POST")

    def do_PUT(self):
        self._handle("PUT")


class FakeGeoServer:
    def __init__(self, username, password, styles=None):
        self.expected = "Basic " + base64.b64encode(f"{username}:{password}".encode("utf-8")).decode("ascii")
        self.styles = dict(styles or {})  # nombre -> SLD tal como se guardó
        self.requests = []  # (método, ruta, Authorization, Content-Type, cuerpo)
        self.server = ThreadingHTTPServer(("127.0.0.1", 0), FakeGeoServerHandler)
        self.server.requests = self.requests
        self.server.script = self._script
        self.server.lock = threading.Lock()
        self.port = self.server.server_address[1]
        self.base_url = f"http://127.0.0.1:{self.port}/geoserver"
        self.thread = threading.Thread(target=self.server.serve_forever, daemon=True)
        self.thread.start()

    def stop(self):
        self.server.shutdown()
        self.server.server_close()

    def writes(self):
        return [(method, path) for method, path, *_ in self.requests if method in ("POST", "PUT")]

    def _script(self, method, full_path, authorization, content_type, body):
        if authorization != self.expected:
            return 401, "HTTP Status 401 - Unauthorized"
        path, _, query = full_path.partition("?")
        params = dict(urllib.parse.parse_qsl(query))
        if path == STYLES and method == "POST":
            name = params.get("name")
            if content_type != SLD_TYPE or not name or params.get("raw") != "true":
                return 400, "an SLD body, ?name= and ?raw=true"
            if name in self.styles:
                return 403, f"Style {name} already exists"
            self.styles[name] = body
            return 201, name
        match = STYLE.match(path)
        if match and method == "GET" and match.group(2):
            name = match.group(1)
            return (200, self.styles[name]) if name in self.styles else (404, f"No such style: {name}")
        if match and method == "PUT" and not match.group(2):
            name = match.group(1)
            if name not in self.styles:
                return 404, f"No such style: {name}"
            if content_type != SLD_TYPE or params.get("raw") != "true":
                return 400, "an SLD body and ?raw=true"
            self.styles[name] = body
            return 200, ""
        return 405, "not scripted"
```

def project_bound(model):
    """Los objetos que llegan a `project` por sus campos RELATION (project, sus raíces y sus hijos, a cualquier distancia):
    la partición de ProjectScope (security.md §9.7), que ArchitectureTest fija contra el código. Los demás son maestros del
    tenant, los únicos que GeoServer puede publicar (§10.2, regla 8)."""
    edges = [(r["source"], r["target"]) for r in model.get("relationships", []) if r.get("fieldName")]
    bound = {"project"}
    grew = True
    while grew:
        grew = False
        for source, target in edges:
            if target in bound and source not in bound:
                bound.add(source)
                grew = True
    return bound

def _sld_errors(where, layer, style, geometry_type, label, colors, styles_dir):
    if not isinstance(colors, dict):
        return [f"{where}: palette.json no tiene los colores de {style}"]
    errors = []
    if colors.get("layer") != layer:
        errors.append(f"{where}: palette.json da {style} a {colors.get('layer')} y layers.json a {layer}")
    try:
        with open(os.path.join(styles_dir, f"{style}.sld"), encoding="utf-8") as f:
            text = f.read()
        root = ET.fromstring(text)
    except OSError:
        return errors + [f"{where}: falta model/styles/{style}.sld"]
    except ET.ParseError as e:
        return errors + [f"{where}: {style}.sld no es XML válido ({e})"]
    name = root.find(f".//{SLD}UserStyle/{SLD}Name")
    if name is None or (name.text or "").strip() != style:
        errors.append(f"{where}: el UserStyle de {style}.sld debe llamarse {style}")
    symbolizer = SYMBOLIZERS[geometry_type]
    if root.find(f".//{SLD}{symbolizer}") is None:
        errors.append(f"{where}: {style}.sld no dibuja la geometría {geometry_type} con un {symbolizer}")
    labels = {(p.text or "").strip() for t in root.iter(f"{SLD}TextSymbolizer") for p in t.iter(f"{OGC}PropertyName")}
    if labels != ({label} if label else set()):
        errors.append(f"{where}: {style}.sld rotula {sorted(labels)} y layers.json pide {label!r} (gis.md §7.2)")
    wanted = {str(colors[key]).lower() for key in PALETTE_COLORS if colors.get(key)}
    used = {color.lower() for color in COLOR.findall(text)}
    if used != wanted:
        errors.append(f"{where}: {style}.sld usa los colores {sorted(used)} y palette.json da {sorted(wanted)}")
    return errors

class GeoServer:
    """La API REST de estilos globales de GeoServer (rest/styles) con autenticación básica."""

    def __init__(self, base_url, username, password):
        self.base_url = base_url.rstrip("/")
        self._authorization = "Basic " + base64.b64encode(f"{username}:{password}".encode("utf-8")).decode("ascii")

    def _call(self, method, path, body=None):
        headers = {"Authorization": self._authorization}
        data = None
        if body is not None:
            headers["Content-Type"] = SLD_TYPE
            data = body.encode("utf-8")
        request = urllib.request.Request(self.base_url + path, data=data, method=method, headers=headers)
        try:
            with urllib.request.urlopen(request, timeout=TIMEOUT_SECONDS) as response:
                return response.status, response.read().decode("utf-8")
        except urllib.error.HTTPError as e:
            return e.code, e.read().decode("utf-8", errors="replace")
        except (urllib.error.URLError, OSError) as e:
            raise PublishError(f"GeoServer no responde en {self.base_url}: {getattr(e, 'reason', e)}") from None

    @staticmethod
    def _refused(what, status, text):
        hint = " (revise WASICHAI_GIS_GEOSERVER_USERNAME y WASICHAI_GIS_GEOSERVER_PASSWORD)" if status == 401 else ""
        return PublishError(f"GeoServer rechazó {what}: {status}{hint} {_excerpt(text)}".rstrip())

    def style(self, name):
        """El SLD guardado del estilo, o None si GeoServer no lo tiene."""
        status, text = self._call("GET", f"/rest/styles/{urllib.parse.quote(name)}.sld")
        if status == 404:
            return None
        if status != 200:
            raise self._refused(f"leer el estilo {name}", status, text)
        return text

    def create_style(self, name, sld):
        status, text = self._call("POST", f"/rest/styles?name={urllib.parse.quote(name)}&raw=true", sld)
        if status != 201:
            raise self._refused(f"el alta del estilo {name}", status, text)
        return status

    def update_style(self, name, sld):
        status, text = self._call("PUT", f"/rest/styles/{urllib.parse.quote(name)}?raw=true", sld)
        if status != 200:
            raise self._refused(f"el cambio del estilo {name}", status, text)
        return status


def publish(client, layers, dry_run):
    """Publica por core las capas de `layers` que faltan. Devuelve (publicadas, omitidas)."""
    status = client.get("/api/gis/layers") or []
    known = {(s["objectName"], s["geometryName"]): s for s in status}
    wanted = pairs(layers)
    missing = [f"{name}.{geometry}" for name, geometry in wanted if (name, geometry) not in known]
    if missing:
        raise PublishError(f"el tenant no tiene {', '.join(missing)}: corra apply.py en este tenant antes de publicar")
    published = skipped = 0
    for name, geometry in wanted:
        current = known[(name, geometry)]
        if current.get("published"):
            print(f"skip   layer {name}.{geometry} ({current.get('layerName')})")
            skipped += 1
            continue
        if dry_run:
            print(f"would publish layer {name}.{geometry}")
        else:
            path = f"/api/gis/layers/{name}/{geometry}"
            try:
                code, body = client.post(path, None)
            except CoreError as e:
                raise PublishError(f"publicar {name}.{geometry} (POST {path}): {e.status} {_excerpt(e.body)}") from None
            print(f"publish layer {name}.{geometry} -> {(body or {}).get('layerName')} ({code})")
        published += 1
    return published, skipped


def load_styles(geoserver, layers, styles_dir, dry_run):
    """Crea o actualiza en GeoServer el SLD de cada estilo. Devuelve (creados, actualizados, omitidos)."""
    created = updated = skipped = 0
    for entry in layers:
        name = entry["style"]
        with open(os.path.join(styles_dir, f"{name}.sld"), encoding="utf-8") as f:
            sld = f.read()
        current = geoserver.style(name)
        if current is not None and same_sld(current, sld):
            print(f"skip   style {name} (same)")
            skipped += 1
            continue
        if dry_run:
            print(f"would {'create' if current is None else 'update'} style {name}")
        elif current is None:
            print(f"create style {name} ({geoserver.create_style(name, sld)})")
        else:
            print(f"update style {name} ({geoserver.update_style(name, sld)})")
        if current is None:
            created += 1
        else:
            updated += 1
    return created, updated, skipped


def _parse_args(argv):
    p = argparse.ArgumentParser(description="Publica las capas públicas de SGSPE en GeoServer y carga sus estilos.")
    p.add_argument("--layers", default=os.path.join(HERE, "layers.json"))
    p.add_argument("--styles", default=os.path.join(HERE, "styles"))
    p.add_argument("--model", default=os.path.join(HERE, "model.json"))
    p.add_argument("--roles", default=os.path.join(HERE, "roles.json"))
    p.add_argument("--core", default=os.environ.get("WASICHAI_CORE", "http://localhost:8094"))
    p.add_argument("--email", default=os.environ.get("WASICHAI_EMAIL", "admin@wasichai.local"))
    p.add_argument("--password", default=os.environ.get("WASICHAI_PASSWORD", "admin"))
    mode = p.add_mutually_exclusive_group()
    mode.add_argument("--dry-run", action="store_true", help="consulta core y GeoServer y dice lo que haría; no escribe")
    mode.add_argument("--validate-only", action="store_true", help="valida layers.json, los SLD y la paleta; sin red")
    return p.parse_args(argv)


def _load(path):
    try:
        with open(path, encoding="utf-8") as f:
            return json.load(f), None
    except (OSError, ValueError) as e:
        return None, f"{path}: {e}"


def main(argv=None):
    try:
        args = _parse_args(sys.argv[1:] if argv is None else argv)
    except SystemExit:
        return 2
    loaded = {}
    for key, path in (("layers", args.layers), ("model", args.model), ("roles", args.roles),
                      ("palette", os.path.join(args.styles, "palette.json"))):
        data, error = _load(path)
        if error:
            print(f"layers: {error}")
            return 2
        loaded[key] = data
    errors = validate(loaded["layers"], loaded["model"], loaded["roles"], loaded["palette"], args.styles)
    if errors:
        for e in errors:
            print(f"layers: {e}")
        return 2
    layers = loaded["layers"]
    if args.validate_only:
        print(f"valid: {len(pairs(layers))} layers, {len(layers)} styles")
        return 0
    settings = tuple((os.environ.get(name) or "").strip() for name in GEOSERVER_VARIABLES)
    if not all(settings):
        missing = ", ".join(name for name, value in zip(GEOSERVER_VARIABLES, settings) if not value)
        print(f"error: faltan {missing}: las credenciales de GeoServer van solo por variables de entorno; un despliegue "
              f"sin GeoServer aprovisiona con --skip-layers", file=sys.stderr)
        return 2
    client = Client(args.core)
    try:
        client.login(args.email, args.password)
    except CoreError as e:
        print(f"error: POST /api/auth/login: {e.status}", file=sys.stderr)
        return 1
    try:
        published, skipped = publish(client, layers, args.dry_run)
        created, updated, kept = load_styles(GeoServer(*settings), layers, args.styles, args.dry_run)
    except CoreError as e:
        print(f"error: core: {e.status} {_excerpt(e.body)}", file=sys.stderr)
        return 1
    except PublishError as e:
        print(f"error: {e}", file=sys.stderr)
        return 1
    word = "dry-run" if args.dry_run else "done"
    print(f"{word}: {len(pairs(layers))} layers ({published} published, {skipped} skipped), {len(layers)} styles "
          f"({created} created, {updated} updated, {kept} skipped)")
    return 0


if __name__ == "__main__":
    sys.exit(main())

    private val lat = SyntheticGeo.ORIGIN.second

    private fun ringOf(polygon: Map<String, Any>): List<List<Double>> = (polygon["coordinates"] as List<List<List<Double>>>).single()

    fun `ORIGIN cae en la zona UTM 17 del hemisferio sur`() {
        assertEquals(17, ((lon + 180) / 6).toInt() + 1)
        assertTrue(lat < 0)
    }

    @Test
    fun `offset mueve metros al norte y al este`() {
        val (sameLon, north) = SyntheticGeo.offset(lon, lat, 0.0, 1000.0)
        assertEquals(lon, sameLon, 0.0)
        assertEquals(1000.0 / 111_320.0, north - lat, 1e-12)

        assertEquals(lat, sameLat, 0.0)
    }

    @Test
    fun `un cuadrado es un anillo cerrado antihorario centrado en el punto`() {
        val ring = ringOf(SyntheticGeo.square(lon, lat, 100.0))
        assertEquals(5, ring.size)
        assertEquals(ring.first(), ring.last())
        // área con signo (fórmula del lazo): positiva si el anillo va en sentido antihorario
        val signed = ring.zipWithNext { a, b -> a[0] * b[1] - b[0] * a[1] }.sum() / 2
        assertTrue(signed > 0, "$signed")
        assertEquals(lon, ring.dropLast(1).map { it[0] }.average(), 1e-12)
        assertEquals(lat, ring.dropLast(1).map { it[1] }.average(), 1e-12)
        assertEquals(SyntheticGeo.offset(lon, lat, 50.0, 0.0).first, ring.maxOf { it[0] }, 0.0)
    }

    @Test
    fun `multiSquare es el mismo cuadrado como MultiPolygon de una parte`() {
        val multi = SyntheticGeo.multiSquare(lon, lat, 100.0)
        assertEquals("MultiPolygon", multi["type"])
        assertEquals(listOf(SyntheticGeo.square(lon, lat, 100.0)["coordinates"]), multi["coordinates"])

package sgspe

import org.springframework.http.HttpStatus
import java.util.UUID
import kotlin.math.cos

// geometrías sintéticas para las pruebas de F6 (RQ-GIS-021): puntos, líneas y cuadrados alrededor de ORIGIN, en la zona UTM
// 17S (EPSG 32717). los metros pasan a grados con la aproximación equirectangular local, que cerca de ORIGIN y hasta unos
// 5 km se aleja menos de 0.5 % de la medida en UTM: las pruebas que miden comparan con tolerancia. ningún dato real
object SyntheticGeo {
    val ORIGIN: Pair<Double, Double> = -78.50 to -7.90

    // metros por grado de latitud (y de longitud en el ecuador)
    private const val METERS_PER_DEGREE = 111_320.0

    fun offset(
        lon: Double,
        lat: Double,
        dxM: Double,
        dyM: Double
    ): Pair<Double, Double> = (lon + dxM / (METERS_PER_DEGREE * cos(Math.toRadians(lat)))) to (lat + dyM / METERS_PER_DEGREE)

    fun point(
        lon: Double,
        lat: Double
    ): Map<String, Any> = mapOf("type" to "Point", "coordinates" to listOf(lon, lat))

    fun line(vararg lonLat: Pair<Double, Double>): Map<String, Any> {
        require(lonLat.size >= 2) { "una línea necesita al menos dos puntos" }
        return mapOf("type" to "LineString", "coordinates" to lonLat.map { listOf(it.first, it.second) })
    }

    // un cuadrado de `sideM` metros centrado en (lon, lat), con el anillo en sentido antihorario
    fun square(
        lon: Double,
        lat: Double,
        sideM: Double
    ): Map<String, Any> = mapOf("type" to "Polygon", "coordinates" to listOf(ring(lon, lat, sideM)))

    // el mismo cuadrado como MultiPolygon de una parte: community.territory y environmental_feature.boundary son MULTIPOLYGON
    fun multiSquare(
        lon: Double,
        lat: Double,
        sideM: Double
    ): Map<String, Any> = mapOf("type" to "MultiPolygon", "coordinates" to listOf(listOf(ring(lon, lat, sideM))))

    private fun ring(
        lon: Double,
        lat: Double,
        sideM: Double
    ): List<List<Double>> {
        require(sideM > 0) { "el lado del cuadrado debe ser positivo" }
        val half = sideM / 2
        val corners = listOf(-half to -half, half to -half, half to half, -half to half, -half to -half)
        return corners.map { (dx, dy) -> offset(lon, lat, dx, dy).let { listOf(it.first, it.second) } }
    }
}

                mapOf("boundary" to boundary)

    // CAMPAMENTO o CAPTACION). un código nuevo en el proyecto es la versión 1
    protected suspend fun component(
        project: UUID,
        code: String,
        type: String,
        geometry: Map<String, Any>

        val body =
            mapOf(
                "attributes" to mapOf("project" to project.toString(), "code" to code, "component_type" to type),
                "geometries" to mapOf(field to geometry)
            )
        return UUID.fromString(tree(send("POST", "/api/sgspe/project-components", body, HttpStatus.CREATED))["component"]["id"].asString())
    }

    // un elemento ambiental con su tipo del catálogo (ZONA DE PROTECCION, FUENTE DE AGUA, MICROCUENCA, CERRO, SITIO SAGRADO o
    // RESTO ARQUEOLOGICO), sus geometrías (boundary es MULTIPOLYGON) y, si se da, su código, único en el tenant desde F6
    protected suspend fun environmentalFeature(
        name: String,
        type: String,
        boundary: Map<String, Any>? = null,
        location: Map<String, Any>? = null,
        code: String? = null
    ): UUID =
        UUID.fromString(
            createWith(
                "environmental_feature",
                mapOf("name" to name, "feature_type" to type, "code" to code).filterValues { it != null },
                geometries("boundary" to boundary, "location" to location)
            )
        )

    // una queja confidencial del proyecto en la localidad. la registra un GRIEVANCE_MANAGER asignado (tiene
    // READ_CONFIDENTIAL, así que puede ser su receptor): la leen el ADMIN y quien tiene READ_CONFIDENTIAL, nunca un CRO ni un
    // ANALYST (security.md §9.6)
    protected suspend fun confidentialGrievance(
        project: UUID,
        locality: UUID
    ): UUID =
        UUID.fromString(
            grievance(
                project.toString(),
                member("GRIEVANCE_MANAGER", project.toString()),
                mapOf("confidential" to true, "locality" to locality.toString())
            )
        )

    private fun geometries(vararg pairs: Pair<String, Map<String, Any>?>): Map<String, Any?> = pairs.filter { it.second != null }.toMap()

    companion object {
        private val COMPONENT_FIELDS = mapOf("Point" to "location", "LineString" to "trace", "Polygon" to "footprint")
    }
}
