# SGSPE · Fase 2, plan 2.1 (modelo y aprovisionamiento): plan de implementación

> **Para agentes:** SUB-SKILL OBLIGATORIA: usar superpowers:subagent-driven-development (recomendada) o
> superpowers:executing-plans para ejecutar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`) para el
> seguimiento. Cada tarea de código sigue superpowers:test-driven-development: prueba que falla, implementación mínima,
> prueba en verde, commit.

**Goal:** Dejar en `~/IdeaProjects/sgspe` el modelo de F2 como código y aprovisionado de punta a punta: los 48 objetos de
F2 en `model/model.json`, los cinco workflows (WF-A, WF-B, WF-C, WF-L y WF-O) en `model/workflows/`, las concesiones de F2
y los campos restringidos de `security.md` §7.9 en `model/roles.json`, los scripts que los aplican (relaciones
MANY_TO_MANY, autorreferencias, índices, valores por defecto y el pase `--workflows`), la carga del ubigeo, los starters
`-gis` y `-workflow`, y las pruebas que lo atan a los documentos (`test_model.py`) y a wasichai de verdad (matriz de
permisos, permisos de campo, transiciones de los cinco workflows y geometrías).

**Architecture:** El modelo sigue siendo datos en `model/` aplicados por REST con Python de solo biblioteca estándar
(ADR-0007). Un lector de los documentos (`model/design_docs.py`) extrae de `docs/database-model.md`,
`docs/requirements-analysis.md` §10, `docs/security.md` §7 y `docs/domain-model.md` §7.3 lo que el modelo, los roles y
los workflows deben ser; dos generadores de un solo uso (que no se versionan) escriben con él `model.json` y
`roles.json`, y `test_model.py`, `test_apply_roles.py` y `test_design_docs.py` los mantienen iguales a los documentos en
adelante. Las pruebas de integración nuevas heredan de `sgspe.F2ApiTest`, que arma registros mínimos válidos de cualquier
objeto desde `model.json` y que ya respeta las guardas del plan 2.2, para que sigan en verde cuando ese plan las agregue.

**Tech Stack:** Kotlin 2.4.20, Spring Boot 4.1.1 (WebFlux), JDK 25, Gradle 9.8.0, `wasichai-bom` 0.3.2 con los starters
core, `-views`, `-forms`, `-pages` y, desde este plan, `-gis` y `-workflow`; JUnit 5 con `wasichai-test`; PostgreSQL 18
con PostGIS 3.6; Python 3.11 o superior (solo biblioteca estándar).

**Spec:** `docs/roadmap.md`, sección «F2 · Proyectos, territorio, grupos de interés y relacionamiento» (filas Alcance,
Objetos, Starters, Workflows, Roles con permisos desde F2 y Definición de terminado) y «Respuestas del checkpoint»;
`.superpowers/sdd/f2-plan-common.md` (reparto entre los planes 2.1, 2.2 y 2.3). Fuentes de cada pieza:
`docs/database-model.md` §2 a §9, §19 (`export_log`), §21, §24 y §25 (fichas, convenciones y aplicación);
`docs/requirements-analysis.md` §10 (valores de los ENUM); `docs/workflows.md` («Mecánica de wasichai», «Formato JSON de un
workflow», WF-A, WF-B, WF-C, WF-L, WF-O, «Transiciones de comando», «Transiciones con motivo obligatorio» y «Pruebas»);
`docs/domain-model.md` §7.3 (estados); `docs/security.md` §4.1, §5, §6.3, §7 y §14; `docs/gis.md` §3.1 y §9;
`docs/architecture.md` §5.4.

## Global Constraints

- **Repositorio.** Todo el trabajo en `~/IdeaProjects/sgspe`, en la rama `feat/fase-2-1-modelo` creada desde `main`
  (que tiene F1, commit `01e0c42`). Los planes 2.2 y 2.3 parten de esta rama ya integrada.
- **Versiones.** `wasichai-bom` 0.3.2; starters nuevos `wasichai:wasichai-spring-boot-starter-gis` y
  `wasichai:wasichai-spring-boot-starter-workflow`, sin versión (las da el BOM); Kotlin 2.4.20; Spring Boot 4.1.1; JDK 25;
  ktlint 1.7.1; imagen `postgis/postgis:18-3.6`.
- **Python.** Solo biblioteca estándar, Python 3.11 o superior. `model/` está fuera de prettier (`.prettierignore`):
  `model.json`, `roles.json` y los workflows tienen el formato a mano que dejan los generadores y los bloques de este plan.
- **Gradle.** Siempre `GITHUB_ACTOR=$(gh api user -q .login) GITHUB_TOKEN=$(gh auth token) ./gradlew …` desde
  `~/IdeaProjects/sgspe`; `./gradlew ktlintFormat` antes de `build`. El token nunca va a un archivo.
- **Integración.** En local, contra la base externa del VPS por el túnel del puerto 5435, con
  `WASICHAI_TEST_DB_HOST=localhost WASICHAI_TEST_DB_PORT=5435 WASICHAI_TEST_DB_NAME=sgspe_test WASICHAI_TEST_DB_USERNAME=sgspe WASICHAI_TEST_DB_PASSWORD=sgspe`
  y `--rerun`; en la CI con Testcontainers. Con el modelo de F2, aprovisionar un tenant por el túnel tarda entre 6 y 8 minutos
  (medido el 2026-10-07: 48 objetos en 1 a 2 min, 113 relaciones en unos 2 min y los 15 roles en 2 a 4 min); la suite
  completa por el túnel, unos 45 minutos (la matriz de permisos sola, unos 18). Los comandos de integración de este plan llevan `timeout` de Bash de
  600000 ms y, si se pasan, `run_in_background`.
- **Base compartida.** `sgspe_test` la usan también los planes 2.2 y 2.3 cuando corren su integración: no correr dos
  suites a la vez contra la misma base (la suite la vacía una vez por JVM).
- **Modelo.** Nombres técnicos en inglés y etiquetas en español (ADR-0009); los valores ENUM en español MAYÚSCULAS sin
  tildes (checkpoint, CON-050, ASM-025). Ningún campo con `editable`; un derivado lleva `"derived": true`.
- **Roles.** Nunca un literal de rol en `src/main/kotlin` (`ArchitectureTest`). Los literales de rol de este plan están en
  `model/` y en `src/test/kotlin`.
- **Datos.** Ningún nombre real de persona: "Persona Ejemplo N" y correos `@sgspe.test`; topónimos públicos (Otuzco,
  Agallpampa, Huanchaco, La Libertad) y códigos inventados (database-model.md §25).
- **Commits.** Conventional Commits con asunto en español; cuerpo de 100 columnas como máximo; al final, tras una línea en
  blanco, `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>` y
  `Claude-Session: https://claude.ai/code/session_017MAgYcNauGp6cC3ekX1h7U`. `git add` solo con rutas explícitas. Push y
  PR solo en la Tarea 16, con la aprobación del usuario.
- **Generadores.** `gen_model_f2.py` y `gen_roles_f2.py` se guardan en el scratchpad de quien ejecuta (fuera del
  repositorio), se corren una vez y no se versionan: desde aquí, `model.json` y `roles.json` se editan a mano y
  `test_model.py` y `test_apply_roles.py` los mantienen iguales a los documentos.

## Review Focus

1. **Subir de fase un tenant que ya tiene el modelo.** Volver a correr `apply.py`, `apply_roles.py` y
   `apply.py --workflows` sobre un tenant ya aprovisionado no crea, cambia ni duplica nada: «done: 0 created, 0 updated,
   168 skipped», «15 skipped» y «5 skipped», contra wasichai de verdad (el núcleo falso no compara campos). Prueba:
   `TenantProvisioningApiTest` (Tarea 9).
2. **Un workflow editado a mano en el lienzo de `/admin`.** Si alguien quita los roles de una transición, la corrida
   siguiente de `apply.py --workflows` lo reemplaza por el del repositorio, y una corrida sin cambios no escribe. Prueba:
   `test_replaces_a_workflow_edited_in_the_admin` y `test_puts_a_missing_workflow_and_skips_it_the_second_time` en
   `model/test_apply.py` (Tarea 3).
3. **Un usuario con dos roles.** Quien tiene `FIELD_AGENT` y `STAKEHOLDER_MANAGER` lee la postura del grupo de interés (gana
   la unión más permisiva), y quien tiene solo `FIELD_AGENT` no recibe ni la clave `stance`. Prueba: `con dos roles gana el
   mas permisivo` y `la postura del grupo de interes no llega a quien no la lee aunque este vacia` en
   `FieldPermissionsApiTest` (Tarea 14).
4. **Guardar una ficha con `u`.** `FIELD_AGENT`, con `u` sobre `stakeholder`, guarda con un PUT sin campos de negocio
   (200) y un PUT que manda `profile_summary` responde 400 nombrando el campo, sin cambiar nada. Prueba: `u deja cambiar el
   registro sin escribir sus campos de negocio` en `FieldPermissionsApiTest` (Tarea 14).
5. **Valores ENUM con las notas del análisis.** «NACIONAL (propuesto)», «(propuestos, salvo RELACION DETERIORADA)» o la
   aclaración de los CRS nunca llegan a una opción, y los valores con espacios («EN CONTRA PERO ABIERTO A ESCUCHAR»,
   «EPSG 32718») pasan el validador de wasichai. Pruebas: `test_las_opciones_salen_del_analisis_sin_notas` en
   `model/test_design_docs.py` (Tarea 4) y `test_ningun_valor_enum_arrastra_notas_del_analisis` en `model/test_model.py`
   (Tarea 5).

```python
    """A defaultValue is text Core keeps as given: an ENUM's must be one of its options, a BOOLEAN's true or false, a
    number's a number. A geometry takes none."""
    value = field["defaultValue"]
    ftype = field.get("type")

    if ftype == "GEOMETRY":
        return [f"{flabel}: a geometry takes no defaultValue"]
    if ftype == "ENUM" and value not in enums.get(field.get("enum"), []):
```

```python
STATE_NAME = re.compile(r"^[a-z][a-z0-9_-]{0,48}$")

def definition_files(model_dir):
    """The definition files under model/, by kind and then by name."""
    found = []
    for kind in DEFINITION_DIRS:
        folder = os.path.join(model_dir, kind)

def validate_workflow(model, object_name, workflow):
    """The errors of model/workflows/<object>.json against model.json and the engine's rules; [] when it is valid."""
    label = f"workflow {object_name}"
    objects = {o["name"]: o for o in model["objects"]}
    if object_name not in objects:
        return [f"{label}: object '{object_name}' is not in model.json"]
    errors = []
    if objects[object_name].get("appendOnly"):
        errors.append(f"{label}: an appendOnly object cannot have a workflow")
    if not WORKFLOW_NAME.fullmatch(str(workflow.get("name", ""))) or not workflow["name"].endswith("-" + object_name):
        errors.append(f"{label}: name must be wf-<letter>-{object_name}")
    if not workflow.get("label"):
        errors.append(f"{label}: label is missing")
    if workflow.get("enabled") is not True:
        errors.append(f"{label}: enabled must be true (ASM-010 is a variant of the definition, not a switch)")
    definition = workflow.get("definition") or {}
    states = definition.get("states") or []
    transitions = definition.get("transitions") or []
    names = [s.get("name") for s in states]
    for state in states:
        if not STATE_NAME.fullmatch(str(state.get("name", ""))) or not state.get("label"):
            errors.append(f"{label}: state {state.get('name')!r} needs a valid name and a label")
        if state.get("type") not in STATE_TYPES:
            errors.append(f"{label}: state {state.get('name')} type must be one of {', '.join(STATE_TYPES)}")
        if "x" in state or "y" in state:
            errors.append(f"{label}: state {state.get('name')} carries x or y; the canvas places it")
    if len(set(names)) != len(names):
        errors.append(f"{label}: a state name repeats")
    if sum(1 for s in states if s.get("type") == "INITIAL") != 1:
        errors.append(f"{label}: exactly one state must be INITIAL")
    finals = {s.get("name") for s in states if s.get("type") == "FINAL"}
    seen = set()
    for t in transitions:
        tname = t.get("name")
        if not STATE_NAME.fullmatch(str(tname or "")) or not t.get("label"):
            errors.append(f"{label}: transition {tname!r} needs a valid name and a label")
        if tname in seen:
            errors.append(f"{label}: transition {tname} repeats")
        seen.add(tname)
        if t.get("from") not in names or t.get("to") not in names:
            errors.append(f"{label}: transition {tname} joins states that do not exist")
        if t.get("from") in finals:
            errors.append(f"{label}: transition {tname} leaves the final state {t.get('from')}")
        if not t.get("roles"):
            errors.append(f"{label}: transition {tname} has no roles (SGSPE never leaves them empty)")
    return errors


def _workflow_body(workflow):
    """What PUT /api/objects/{object}/workflow takes, and what GET answers once normalized: name, label, enabled and the
    definition without positions."""
    definition = workflow.get("definition") or {}
    return {
        "name": workflow["name"],
        "label": workflow["label"],
        "enabled": workflow.get("enabled", True),
        "definition": {
            "states": [{"name": s["name"], "label": s["label"], "type": s.get("type") or "INTERMEDIATE"}
                       for s in definition.get("states", [])],
            "transitions": [{"name": t["name"], "label": t["label"], "from": t["from"], "to": t["to"],
                             "roles": list(t.get("roles", []))} for t in definition.get("transitions", [])],
        },
    }


def load_workflows(model_dir, model):
    """(object, workflow) for each model/workflows/<object>.json, and the errors of all of them."""
    loaded, errors = [], []
    folder = os.path.join(model_dir, "workflows")
    for name in sorted(os.listdir(folder)) if os.path.isdir(folder) else []:
        if not name.endswith(".json"):
            continue
        object_name = name[:-len(".json")]
        try:
            with open(os.path.join(folder, name), encoding="utf-8") as f:
                workflow = json.load(f)
        except ValueError as e:
            errors.append(f"model/workflows/{name}: not valid JSON: {e}")
            continue
        found = validate_workflow(model, object_name, workflow)
        errors.extend(f"model/workflows/{name}: {e}" for e in found)
        if not found:
            loaded.append((object_name, workflow))
    return loaded, errors


def do_workflows(model_dir, model, client_factory, dry_run=False):
    """The workflows of model/workflows/: a missing one is created, one that differs is replaced (PUT is the whole
    api), an equal one is skipped. A definition of a kind that has not arrived yet is an error, never a silent skip."""
    early = [path for path in definition_files(model_dir) if path.split("/")[0] not in APPLIED_KINDS]
    if early:
        for path in early:
            print(f"error: model/{path}: apply.py --workflows does not apply this kind yet; it arrives with its phase",
                  file=sys.stderr)
        return 2
    workflows, errors = load_workflows(model_dir, model)
    if errors:
        for error in errors:
            print(f"error: {error}", file=sys.stderr)
        return 2
    if dry_run:
        for object_name, workflow in workflows:
            print(f"# PUT /api/objects/{object_name}/workflow")
            print(json.dumps(_workflow_body(workflow), indent=2, ensure_ascii=False))
        return 0
    created = updated = skipped = 0
    client = client_factory() if workflows else None
    for object_name, workflow in workflows:
        path = f"/api/objects/{object_name}/workflow"
        wanted = _workflow_body(workflow)
        try:
            current = client.get(path)
        except CoreError as e:
            _fatal("GET", path, e)
            return 1
        if current is not None and _workflow_body(current) == wanted:
            print(f"skip   workflow {wanted['name']} (up to date)")
            skipped += 1
            continue
        try:
            client.put(path, wanted)
        except CoreError as e:
            _fatal("PUT", path, e)
            return 1
        if current is None:
            print(f"create workflow {wanted['name']}")
            created += 1
        else:
            print(f"update workflow {wanted['name']}")
            updated += 1
    print(f"done: {len(workflows)} workflows ({created} created, {updated} updated, {skipped} skipped), "
          f"0 document types, 0 automations, 0 views, 0 forms, 0 pages")
    return 0
```

```python
Stdlib only. What it reads, and from where:

- docs/database-model.md, the cards (§6 to §21): per object its label, description, fields (type, required, unique,
  derived, restricted, default, phase), relationships (type, field, target, required, phase), flags, uniques, declared
  indexes, declared actions, workflow and phase; §4, the key of each ENUM catalog;
- docs/requirements-analysis.md §10, the options of each catalog, in order, without the "(propuesto)" notes;
- docs/security.md §7.1 (the phase of each role), §7.2 to §7.8 (the matrix) and §7.9 (the restricted fields);
- docs/domain-model.md §7.3, the states of each workflow.

A phase is "F2", "F3"... and compares as text, which works from F1 to F8.
"""
import os
import re

HERE = os.path.dirname(os.path.abspath(__file__))
DOCS = os.path.join(os.path.dirname(HERE), "docs")

TICK = re.compile(r"`([^`]+)`")
PARENS = re.compile(r"\s*\([^()]*\)")
FROM_PHASE = re.compile(r"[Dd]esde (F\d)")
DEFAULT = re.compile(r"Por defecto: ([^.]+)\.")


def read(name):
    with open(os.path.join(DOCS, name), encoding="utf-8") as f:
        return f.read()


def table_rows(lines, start):
    """The rows of the markdown table that starts at lines[start] (its header), as lists of stripped cells."""
    rows = []
    i = start + 2  # header and separator
    while i < len(lines) and lines[i].startswith("|"):
        cells = [c.strip() for c in lines[i].strip().strip("|").split("|")]
        rows.append(cells)
        i += 1
    return rows


def ticks(text):
    return TICK.findall(text)


def strip_parens(text):
    previous = None
    while previous != text:
        previous, text = text, PARENS.sub("", text)
    return text.strip()


# ---------------------------------------------------------------------------
# database-model.md: the cards
# ---------------------------------------------------------------------------

class Card:
    def __init__(self, name):
        self.name = name
        self.label = ""
        self.description = ""
        self.fields = []  # dicts: name, type, enum, geometryType, required, unique, composite, derived, restricted,
        #                   default, phase, description
        self.relationships = []  # dicts: name, type, field, target, required, note, phase, restricted
        self.flags = {}
        self.unique = []  # field names with unique: true
        self.unique_constraints = []  # lists of field names
        self.indexed = []  # field names with indexed: true
        self.indexes = []  # lists of field names
        self.actions = []
        self.workflow = None
        self.phase = None
        self.exactly_one = []  # lists of relation field names


def _bullets(lines, start):
    """The '- **Key:** value' bullets after a card's tables, continuation lines joined, until the next heading."""
    bullets = {}
    i = start
    current = None
    while i < len(lines) and not lines[i].startswith("#"):
        line = lines[i]
        match = re.match(r"^- \*\*([^*]+?):?\*\*:? ?(.*)$", line)
        if match:
            current = match.group(1).rstrip(":")
            bullets[current] = match.group(2)
        elif current and line.startswith("  ") and line.strip():
            bullets[current] += " " + line.strip()
        else:
            current = None
        i += 1
    return bullets


def _field_type(cell):
    """('ENUM', 'stance', None) from 'ENUM `stance`'; ('GEOMETRY', None, 'POINT') from 'GEOMETRY (POINT)'."""
    if cell.startswith("ENUM"):
        return "ENUM", ticks(cell)[0], None
    if cell.startswith("GEOMETRY"):
        return "GEOMETRY", None, re.search(r"\((\w+)\)", cell).group(1)
    return cell, None, None


def _sets(text):
    """[['a', 'b'], ['c', 'd']] from "(`a`, `b`); (`c`, `d`)"."""
    return [ticks(group) for group in re.findall(r"\(([^()]*)\)", text) if ticks(group)]


def cards():
    """Every card of database-model.md, by name, in document order (dicts keep it)."""
    lines = read("database-model.md").splitlines()
    found = {}
    i = 0
    while i < len(lines):
        heading = re.match(r"^### `([a-z_]+)`$", lines[i])
        if not heading:
            i += 1
            continue
        card = Card(heading.group(1))
        j = i + 1
        while not lines[j].strip():
            j += 1
        intro = []
        while lines[j].strip():
            intro.append(lines[j].strip())
            j += 1
        intro = " ".join(intro)
        card.label = re.match(r"^\*\*([^*]+)\*\*", intro).group(1)
        body = re.sub(r"^\*\*[^*]+\*\* \([^)]*\)\. ", "", intro)
        card.description = body.split(" Tabla física")[0].strip()
        while j < len(lines) and not lines[j].startswith("#"):
            if lines[j].startswith("| Campo |"):
                for name, ftype, req, uniq, desc, _src in table_rows(lines, j):
                    kind, enum, geometry = _field_type(ftype)
                    phase = FROM_PHASE.search(desc)
                    default = DEFAULT.search(desc)
                    card.fields.append({
                        "name": ticks(name)[0], "type": kind, "enum": enum, "geometryType": geometry,
                        "required": req == "sí", "unique": uniq == "sí", "composite": uniq == "compuesto",
                        "derived": "(derivado)" in desc, "restricted": "(restringido)" in desc,
                        "default": default.group(1).strip() if default else None,
                        "phase": phase.group(1) if phase else None, "description": desc,
                    })
            elif lines[j].startswith("| Relación |"):
                for name, rtype, field, target, req, note in table_rows(lines, j):
                    phase = FROM_PHASE.search(note)
                    card.relationships.append({
                        "name": ticks(name)[0], "type": rtype, "field": (ticks(field) or [None])[0],
                        "target": ticks(target)[0], "required": req == "sí", "note": note,
                        "phase": phase.group(1) if phase else None, "inverse": note.startswith("Inversa"),
                        "restricted": "restringido" in note,
                    })
            elif lines[j].startswith("- **"):
                bullets = _bullets(lines, j)
                flags = bullets.get("Flags", "")
                card.flags = {flag: bool(re.search(rf"`{flag}` sí", flags)) for flag in ("appendOnly", "apiOnly", "requiresReason")}
                uniques = bullets.get("Únicos", "ninguno")
                if uniques.startswith("`unique` en"):
                    card.unique = ticks(uniques)[1:]
                elif uniques.startswith("`uniqueConstraints`"):
                    card.unique_constraints = _sets(uniques)
                indexes = bullets.get("Índices declarados", "ninguno")
                if indexes.startswith("`indexed` en"):
                    card.indexed = ticks(indexes)[1:]
                elif indexes.startswith("`indexes`"):
                    card.indexes = _sets(indexes)
                card.actions = [a for a in ticks(bullets.get("Acciones declaradas", "")) if a.isupper()]
                workflow = re.match(r"(WF-[A-Z0-9]+)", bullets.get("Workflow", ""))
                card.workflow = workflow.group(1) if workflow else None
                phase = re.match(r"(F\d)", bullets.get("Fase", ""))
                card.phase = phase.group(1) if phase else None
                card.exactly_one = _sets(bullets.get("Exactamente uno de", ""))
                break
            j += 1
        found[card.name] = card
        i = j
    return found


def field_phase(card, field):
    return max(card.phase, field["phase"] or card.phase)


def relationship_phase(all_cards, card, rel):
    """A relationship arrives when both ends exist, or later if its note says so."""
    return max(card.phase, all_cards[rel["target"]].phase, rel["phase"] or "F0")


def enum_keys():
    """{catalog name of §10: enums key} from database-model.md §4. A sub-list row maps to (catalog, index)."""
    lines = read("database-model.md").splitlines()
    start = next(i for i, line in enumerate(lines) if line.startswith("| Catálogo de §10 |"))
    keys = {}
    sub_count = {}
    for catalog, key, _uses in table_rows(lines, start):
        if not ticks(key):
            continue  # "no aplica": the document types are not an ENUM
        sub = re.match(r"^(.*) \(sub-lista de [^)]+\)$", catalog)
        if sub:
            base = sub.group(1)
            index = sub_count.get(base, 0)
            sub_count[base] = index + 1
            keys[ticks(key)[0]] = (base, index)
        else:
            keys[ticks(key)[0]] = (catalog, None)
    return keys


def _options(text):
    return [strip_parens(o).strip() for o in strip_parens(text).split(" · ")]


def catalogs():
    """{enums key: [options]} from requirements-analysis.md §10, for every key of database-model.md §4."""
    lines = read("requirements-analysis.md").splitlines()
    start = next(i for i, line in enumerate(lines) if line.startswith("| Catálogo | Valores |"))
    values = {row[0]: row[1] for row in table_rows(lines, start)}
    result = {}
    for key, (catalog, index) in enum_keys().items():
        text = values[catalog]
        if index is None:
            result[key] = _options(text)
            continue
        if ":" in text:  # "Sujeto: A · B. Polaridad: C · D"
            parts = [p.split(":", 1)[1] for p in re.split(r"\.\s+(?=[A-ZÁÉÍÓÚ][a-záéíóú]+:)", text)]
        else:  # "A · B; C · D; E · F"
            parts = text.split(";")
        result[key] = _options(parts[index].strip().rstrip("."))
    return result

def role_phases():
    """{role: phase} and {abbreviation: role} from security.md §7.1."""
    lines = read("security.md").splitlines()
    start = next(i for i, line in enumerate(lines) if line.startswith("| Abrev. | Rol |"))
    phases, roles = {}, {}
    for abbr, role, phase, _what in table_rows(lines, start):
        name = ticks(role)[0]
        phases[name] = phase
        roles[abbr] = name
    return phases, roles


def _grants(cell):
    """['READ', 'CREATE', 'u', 'APPROVE'] from 'CRu `APPROVE`'; [] from '—'."""
    if cell == "—":
        return []
    letters = cell.split("`")[0].strip()
    order = {"R": "READ", "C": "CREATE", "U": "UPDATE", "u": "u", "D": "DELETE"}
    grants = [order[k] for k in ("R", "C", "U", "u", "D") if k in letters]
    return grants + ticks(cell)


def matrix():
    """{object: {role: [grants]}} from every table of security.md §7.2 to §7.8, as written (every phase)."""
    lines = read("security.md").splitlines()
    _, roles = role_phases()
    result = {}
    for i, line in enumerate(lines):
        if not line.startswith("| Objeto | PAD |"):
            continue
        header = [c.strip() for c in line.strip().strip("|").split("|")]
        for cells in table_rows(lines, i):
            obj = ticks(cells[0])[0]
            result[obj] = {roles[abbr]: _grants(cell) for abbr, cell in zip(header[1:], cells[1:])}
    return result


def restricted_fields():
    """[(object, field, [readers])] from security.md §7.9, in table order."""
    lines = read("security.md").splitlines()
    start = next(i for i, line in enumerate(lines) if line.startswith("| Campo | Dato | Roles que conservan acceso |"))
    declared, _ = role_phases()
    result = []
    for name, _what, readers, _source in table_rows(lines, start):
        names = ticks(name)
        # solo los roles: la fila de evidence_quote nombra además la acción DOWNLOAD_RESTRICTED
        roles = [r for r in ticks(readers) if r in declared]
        if "." not in names[0]:  # "`person` de `grievance`, `inquiry` y `stakeholder_request`"
            pairs = [(obj, names[0]) for obj in names[1:]]
        else:
            pairs, current = [], None
            for token in names:
                if "." in token:
                    current, field = token.split(".", 1)
                else:
                    field = token
                pairs.append((current, field))
        result.extend((obj, field, roles) for obj, field in pairs)
    return result

# ---------------------------------------------------------------------------

def workflow_states():
    """{object: {"INITIAL": [...], "INTERMEDIATE": [...], "FINAL": [...]}} with (name, label) pairs."""
    lines = read("domain-model.md").splitlines()
    start = next(i for i, line in enumerate(lines) if line.startswith("| WF | Objeto | Inicial |"))
    result = {}

    def states(cell):
        return [(m.group(1), m.group(2).split(";")[0].strip()) for m in re.finditer(r"`([a-z_]+)` \(([^)]*)\)", cell)]

    for _wf, objects, initial, middle, final in table_rows(lines, start):
        for obj in ticks(objects):
            result[obj] = {"INITIAL": states(initial), "INTERMEDIATE": states(middle), "FINAL": states(final)}
    return result
```

```python
def field_label(obj, field):
    if (obj, field["name"]) in FIELD_LABEL:
        return FIELD_LABEL[(obj, field["name"])]
    text = field["description"].replace("(derivado)", "").replace("(restringido)", "").replace('"', "").strip()
    text = d.strip_parens(text)
    text = re.split(r"; |: |\. |, |\.$", text)[0]
    return text.strip().rstrip(".")


def relationship_label(cards, rel):
    if rel["name"] in RELATIONSHIP_LABEL:
        return RELATIONSHIP_LABEL[rel["name"]]
    if rel["note"] == "—":
        return cards[rel["target"]].label
    return d.strip_parens(rel["note"].split(";")[0]).strip()


def default_value(field):
    return field["default"]


def build():
    cards = d.cards()
    catalogs = d.catalogs()
    objects, relationships, used = [], [], []
    for name, card in cards.items():
        if card.phase != PHASE:
            continue
        fields = []
        for f in card.fields:
            if d.field_phase(card, f) != PHASE:
                continue
            out = {"name": f["name"], "label": field_label(name, f), "type": f["type"]}
            if f["type"] == "ENUM":
                out["enum"] = f["enum"]
                if f["enum"] not in used:
                    used.append(f["enum"])
            if f["type"] == "GEOMETRY":
                out.update({"geometryType": f["geometryType"], "srid": 4326, "dimension": 2})
            if f["required"]:
                out["required"] = True
            if f["unique"]:
                out["unique"] = True
            if f["name"] in card.indexed:
                out["indexed"] = True
            if f["derived"]:
                out["derived"] = True
            if default_value(f) is not None:
                out["defaultValue"] = default_value(f)
            out["description"] = f["description"].replace("`", "")
            fields.append(out)
        obj = {"name": name, "label": card.label, "pluralLabel": PLURAL[name], "description": card.description.replace("`", "")}
        obj.update({flag: True for flag, on in card.flags.items() if on})
        if card.unique_constraints:
            obj["uniqueConstraints"] = card.unique_constraints
        if card.indexes:
            obj["indexes"] = card.indexes
        if card.actions:
            obj["actions"] = [{"name": a, "label": ACTION_LABEL[a]} for a in card.actions]
        obj["fields"] = fields
        objects.append(obj)
        for rel in card.relationships:
            if rel["inverse"] or d.relationship_phase(cards, card, rel) != PHASE:
                continue
            out = {"name": rel["name"]}
            if rel["type"] == "MANY_TO_MANY":
                out["type"] = "MANY_TO_MANY"
            out.update({"label": relationship_label(cards, rel), "inverseLabel": PLURAL[name], "source": name,
                        "target": rel["target"]})
            if rel["type"] == "MANY_TO_ONE":
                out["fieldName"] = rel["field"]
                if rel["required"]:
                    out["required"] = True
            relationships.append(out)
    enums = {key: catalogs[key] for key in sorted(used)}
    return {"enums": enums, "objects": objects, "relationships": relationships}

def dump(model):
    """The hand layout of model.json: one enum, field or relationship per line."""
    line = lambda value: json.dumps(value, ensure_ascii=False)  # noqa: E731
    out = ["{", '  "enums": {']
    keys = list(model["enums"])
    for i, key in enumerate(keys):
        out.append(f"    {line(key)}: {line(model['enums'][key])}{',' if i < len(keys) - 1 else ''}")
    out.append("  },")
    out.append('  "objects": [')
    for i, obj in enumerate(model["objects"]):
        out.append("    {")
        head = [k for k in obj if k != "fields"]
        for k in head:
            out.append(f"      {line(k)}: {line(obj[k])},")
        out.append('      "fields": [')
        for j, field in enumerate(obj["fields"]):
            out.append(f"        {line(field)}{',' if j < len(obj['fields']) - 1 else ''}")
        out.append("      ]")
        out.append("    }" + ("," if i < len(model["objects"]) - 1 else ""))
    out.append("  ],")
    out.append('  "relationships": [')
    for i, rel in enumerate(model["relationships"]):
        out.append(f"    {line(rel)}{',' if i < len(model['relationships']) - 1 else ''}")
    out.append("  ]")
    out.append("}")
    return "\n".join(out) + "\n"


if __name__ == "__main__":
```

```python
    """Los errores de restrictedFields: cada entrada nombra un objeto del modelo, campos suyos sin repetir y lectores

    if not isinstance(entries, list):

    for entry in entries:
        if not isinstance(entry, dict) or not {"object", "fields", "readers"} <= set(entry):
            errors.append(f"restrictedFields: {entry!r} must have object, fields and readers")
```

```python
#!/usr/bin/env python3
"""Carga el ubigeo del INEI en administrative_unit (RF-TER-001, ASM-016): departamentos, provincias y distritos con su
jerarquía en parent_unit.

Solo biblioteca estándar. Lee model/data/ubigeo.csv (columnas codigo, departamento, provincia y distrito, una fila por
distrito; copiado de srtm-backend, model/data/ubigeo.csv) y deriva de cada código de seis dígitos el departamento
(<2 dígitos>0000) y la provincia (<4 dígitos>00). Una fila cuyo código no tiene seis dígitos se informa y se salta.

Es idempotente (security.md §4.1, paso 5): una unidad que core no tiene se crea, una cuyo nombre, nivel o unidad
superior cambió se reemplaza con un PUT de sus cuatro atributos (el límite, una geometría, no se toca) y las demás se
saltan. Nunca borra. Corre después de apply.py, con el administrador del tenant.

Correr: python3 load_ubigeo.py [--csv C] [--dry-run] [--core URL] [--email E] [--password P]
Salida: 0 si va bien, 1 si core rechaza algo o no responde, 2 si el CSV falta o no tiene las columnas.
"""
import argparse
import csv
import os
import re
import sys

from core_client import Client, CoreError

HERE = os.path.dirname(os.path.abspath(__file__))
OBJECT = "administrative_unit"
COLUMNS = ("codigo", "departamento", "provincia", "distrito")
CODE = re.compile(r"^\d{6}$")
LEVELS = ("DEPARTAMENTO", "PROVINCIA", "DISTRITO")


class CsvError(Exception):
    pass


def read_units(path):
    """Las unidades del CSV, departamentos primero, después provincias y después distritos, cada nivel por código, y las
    filas saltadas como (número de línea, código). Una unidad es {ubigeo_code, name, level, parent}."""
    try:
        with open(path, encoding="utf-8", newline="") as f:
            reader = csv.DictReader(f)
            if reader.fieldnames is None or not set(COLUMNS) <= set(reader.fieldnames):
                raise CsvError(f"{path}: needs the columns {', '.join(COLUMNS)}")
            rows = list(enumerate(reader, start=2))
    except OSError as e:
        raise CsvError(f"{path}: {e.strerror or e}") from e
    units, skipped = {}, []
    for line, row in rows:
        code = (row["codigo"] or "").strip()
        if not CODE.fullmatch(code):
            skipped.append((line, code))
            continue
        department, province = code[:2] + "0000", code[:4] + "00"
        units.setdefault(department, {"ubigeo_code": department, "name": row["departamento"].strip(),
                                      "level": "DEPARTAMENTO", "parent": None})
        units.setdefault(province, {"ubigeo_code": province, "name": row["provincia"].strip(),
                                    "level": "PROVINCIA", "parent": department})
        units[code] = {"ubigeo_code": code, "name": row["distrito"].strip(), "level": "DISTRITO", "parent": province}
    ordered = sorted(units.values(), key=lambda u: (LEVELS.index(u["level"]), u["ubigeo_code"]))
    return ordered, skipped


def load(client, units):
    """Crea, reemplaza o salta cada unidad en orden, para que la superior ya tenga id. Devuelve (creadas,
    actualizadas, saltadas)."""
    existing = {r["attributes"]["ubigeo_code"]: r for r in client.list_all(OBJECT)}
    ids = {code: record["id"] for code, record in existing.items()}
    created = updated = skipped = 0
    for unit in units:
        attributes = {"ubigeo_code": unit["ubigeo_code"], "name": unit["name"], "level": unit["level"],
                      "parent_unit": ids.get(unit["parent"]) if unit["parent"] else None}
        current = existing.get(unit["ubigeo_code"])
        if current is None:
            _, body = client.post(f"/api/objects/{OBJECT}/records", {"attributes": attributes})
            ids[unit["ubigeo_code"]] = body["id"]
            created += 1
        elif any(current["attributes"].get(k) != v for k, v in attributes.items()):
            client.put(f"/api/objects/{OBJECT}/records/{current['id']}", {"attributes": attributes})
            print(f"update {unit['level'].lower()} {unit['ubigeo_code']} {unit['name']}")
            updated += 1
        else:
            skipped += 1
    return created, updated, skipped


def _parse_args(argv):
    p = argparse.ArgumentParser(description="Carga el ubigeo del INEI en administrative_unit.")
    p.add_argument("--csv", default=os.path.join(HERE, "data", "ubigeo.csv"))

def main(argv=None):

    try:
        units, skipped_rows = read_units(args.csv)
    except CsvError as e:

        return 2
    for line, code in skipped_rows:
```

```kotlin
import org.springframework.http.HttpStatus
```

```kotlin
import java.io.File

// la base de las pruebas de integración de F2 (plan 2.1): registros mínimos válidos de los 48 objetos, armados desde
// model/model.json, usuarios con un rol y su asignación al proyecto de la clase, y las llamadas de workflow. los

// asignación, sin campos derivados), para que estas pruebas sigan en verde cuando lleguen
abstract class F2ApiTest : SgspeApiTest() {

            )

        projectId: String = testProject()

    // un registro mínimo válido de `objectName`, creado como `account` (el admin si es null)
    protected fun fixture(
        objectName: String,
        overrides: Map<String, Any?> = emptyMap(),
        account: Account? = null
    ): Fixture {
        val attributes = sample(objectName) + overrides
        val headers = if (requiresReason(objectName)) mapOf(REASON to reason("alta de prueba")) else emptyMap()
        val id = createRecord(objectName, attributes, headers, account?.token ?: token)
        return Fixture(id, attributes)

    protected open fun adminFixture(objectName: String): Fixture =
        adminFixtures.getOrPut(objectName) {
            if (objectName == "project") {
                Fixture(testProject(), tree(send("GET", "/api/objects/project/records/${testProject()}", null, HttpStatus.OK)).let { attributesOf(it) })
            } else {

            }

    protected fun sample(objectName: String): Map<String, Any?> {
        val obj = Model.objects.getValue(objectName)
        val n = SEQUENCE.incrementAndGet()
        val inSets = (obj["uniqueConstraints"] as List<List<String>>?).orEmpty().flatten().toSet()
        val fixed = FIXED[objectName].orEmpty()
        val attributes = linkedMapOf<String, Any?>()
        var radix = n
        for (field in obj["fields"] as List<Map<String, Any?>>) {
            val name = field["name"] as String
            val type = field["type"] as String
            val required = field["required"] == true
            val unique = field["unique"] == true
            if (field["derived"] == true || type == "GEOMETRY") continue
            when {
                name in fixed -> attributes[name] = fixed[name]
                type == "ENUM" && name in inSets -> {
                    val options = Model.enums.getValue(field["enum"] as String)
                    attributes[name] = options[radix % options.size]
                    radix /= options.size
                }
                type == "INTEGER" && name in inSets -> attributes[name] = n
                !(required || unique || name in inSets) -> Unit
                name.endsWith("_user_id") -> {
                    val user = userWithRole("READ_ONLY")
                    attributes[name] = user.id
                    attributes[name.removeSuffix("_id") + "_email"] = user.email
                }
                name.endsWith("_user_email") -> Unit
                type == "TEXT" -> attributes[name] = if (unique || name in inSets) uniqueName("${name.take(6)}-") else "Prueba $name"
                type == "LONG_TEXT" -> attributes[name] = "Texto de prueba"
                type == "INTEGER" || type == "DECIMAL" -> attributes[name] = 1
                type == "BOOLEAN" -> attributes[name] = true
                type == "DATE" -> attributes[name] = "2026-10-07"
                type == "DATETIME" -> attributes[name] = "2026-10-07T15:00:00Z"
                type == "ENUM" -> attributes[name] = Model.enums.getValue(field["enum"] as String).first()

    @Suppress("UNCHECKED_CAST")

            .filter { it["derived"] == true }
            .map { it["name"] as String }

        id: String
    ): String = tree(send("GET", "/api/objects/$objectName/records/$id", null, HttpStatus.OK))["state"].asString()

        id: String,

    // model/model.json y model/roles.json, leídos una vez por JVM
    @Suppress("UNCHECKED_CAST")
```

```kotlin
package sgspe.security

import org.junit.jupiter.api.Assertions.assertEquals
import org.junit.jupiter.params.ParameterizedTest
import org.junit.jupiter.params.provider.MethodSource
import org.springframework.http.HttpStatus
import sgspe.F2ApiTest

// security.md §14, «Matriz de permisos» (RQ-SEC-004, RQ-SEC-017): parametrizada desde model/roles.json, cada rol lee,
// crea, cambia y borra cada objeto de model.json según sus permisos, y recibe 403 donde no los tiene. `u` cambia el
// registro sin campos de negocio. un objeto apiOnly rechaza el alta por la API genérica a todos. cada rol escribe lo que
// crea él mismo, en el proyecto al que está asignado, y devuelve los derivados con su valor, para que la prueba valga
// también con las guardas del plan 2.2
class PermissionMatrixApiTest : F2ApiTest() {
    // los 15 roles comparten el proyecto y el registro del admin de cada objeto: por el túnel, armarlos una vez por rol
    // triplica la duración
    override fun testProject(): String = SHARED.project ?: super.testProject().also { SHARED.project = it }

    override fun adminFixture(objectName: String): Fixture = SHARED.fixtures.getOrPut(objectName) { super.adminFixture(objectName) }

    @ParameterizedTest(name = "{0}")
    @MethodSource("roles")
    fun `cada objeto responde a cada accion como dice roles json`(role: String) {
        val account = member(role)
        val grants = Model.roles.getValue(role)
        val readsTenant = grants["*"]?.contains("READ") == true
        val failures = mutableListOf<String>()

        fun expect(
            what: String,
            wanted: HttpStatus,
            response: Response
        ) {
            if (response.status != wanted) failures += "$what: $wanted esperado, ${response.status} ${response.body.take(300)}"
        }

        for ((name, obj) in Model.objects) {
            val actions = grants[name].orEmpty()
            val headers = if (requiresReason(name)) mapOf(REASON to reason("matriz de permisos")) else emptyMap()
            val records = "/api/objects/$name/records"
            expect(
                "$name READ",
                if ("READ" in actions ||
                    readsTenant
                ) {
                    HttpStatus.OK
                } else {
                    HttpStatus.FORBIDDEN
                },
                exchange("GET", "$records?size=1", token = account.token)
            )
            if (obj["apiOnly"] == true) {
                expect(
                    "$name CREATE (apiOnly)",
                    HttpStatus.FORBIDDEN,
                    exchange("POST", records, mapOf("attributes" to emptyMap<String, Any>()), account.token, headers)
                )
                continue
            }
            var own: Fixture? = null
            if ("CREATE" in actions) {
                val attributes = sample(name)
                val created = exchange("POST", records, mapOf("attributes" to attributes), account.token, headers)
                expect("$name CREATE", HttpStatus.CREATED, created)
                if (created.status == HttpStatus.CREATED) own = Fixture(tree(created.body)["id"].asString(), attributes)
            } else {
                expect("$name CREATE", HttpStatus.FORBIDDEN, exchange("POST", records, mapOf("attributes" to emptyMap<String, Any>()), account.token, headers))
            }
            // el proyecto que se cambia es el de la prueba, al que el rol está asignado
            val target = if (name == "project") adminFixture("project") else own ?: adminFixture(name)
            // un PUT reemplaza el registro: se devuelve lo que el rol lee (con UPDATE) o solo los derivados (con `u`), como
            // el portal; los campos que el rol no lee no llegan y wasichai los conserva
            val current =
                if ("READ" in actions ||
                    readsTenant
                ) {
                    attributesOf(tree(send("GET", "$records/${target.id}", null, HttpStatus.OK, account.token)))
                } else {
                    emptyMap()
                }
            val body =
                when {
                    "UPDATE" in actions -> current
                    "u" in actions -> current.filterKeys { it in derivedFields(name) }
                    else -> emptyMap()
                }
            val updated = if ("UPDATE" in actions || "u" in actions) HttpStatus.OK else HttpStatus.FORBIDDEN
            expect("$name UPDATE", updated, exchange("PUT", "$records/${target.id}", mapOf("attributes" to body), account.token, headers))
            val victim = own ?: target
            expect(
                "$name DELETE",
                if ("DELETE" in
                    actions
                ) {
                    HttpStatus.NO_CONTENT
                } else {
                    HttpStatus.FORBIDDEN
                },
                exchange("DELETE", "$records/${victim.id}", token = account.token, headers = headers)
            )
        }
        assertEquals(emptyList<String>(), failures, "$role:\n${failures.joinToString("\n")}")
    }

    companion object {
        @JvmStatic
        fun roles(): List<String> = Model.roles.keys.toList()

        private object SHARED {
            var project: String? = null
            val fixtures = mutableMapOf<String, Fixture>()
        }
    }
}
```

```kotlin
import org.junit.jupiter.api.Assertions.assertFalse

import org.junit.jupiter.api.Test
import org.springframework.http.HttpStatus

// security.md §7.9 y §14, «Permisos de campo» (RQ-SEC-010): un campo restringido no llega al registro, a la lista, al
// historial ni a la auditoría de quien no lo lee, y escribirlo se rechaza nombrando el campo; quien lo lee lo ve. las
// exportaciones las prueba el plan 2.2 con su endpoint

    private fun record(
        objectName: String,
        id: String,
        account: Account
    ) = tree(send("GET", "/api/objects/$objectName/records/$id", null, HttpStatus.OK, account.token))["attributes"]

    // el registro tal como sale en la lista, filtrada por un campo legible con un valor único
    private fun listed(
        objectName: String,
        filter: Pair<String, String>,
        account: Account
    ) = tree(send("GET", "/api/objects/$objectName/records?${filter.first}=${filter.second}", null, HttpStatus.OK, account.token))["content"]
        .values()
        .single()["attributes"]

        objectName: String,
        id: String,
        account: Account
    ) = tree(send("GET", "/api/objects/$objectName/records/$id/history", null, HttpStatus.OK, account.token))
        .values()
        .flatMap { entry -> entry["changes"].values().map { it["field"].asString() } }
        .toSet()

    private fun change(

        fixture: Fixture,

        val officer = userWithRole("COMMUNITY_RELATIONS_OFFICER")
        val restricted = setOf("given_names", "surnames", "id_document_number")

        for (view in listOf(record("person", person.id, readOnly), listed("person", "id_document_type" to kind, readOnly))) {
            assertTrue(restricted.none { view.has(it) }, view.toString())
            assertEquals(kind, view["id_document_type"].asString())

        assertTrue(historyFields("person", person.id, readOnly).intersect(restricted).isEmpty())
```
