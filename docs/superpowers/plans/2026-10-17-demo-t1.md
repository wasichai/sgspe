## Formato de `model/demo/*.json` (contrato de todas las tareas)

El cargador lee los archivos `model/demo/NN-*.json` en orden de nombre y comparte un único espacio de claves. Cada archivo
es:

```json
{
  "anchor": {"lat": -13.20, "lon": -75.65},
  "users": [
    {"key": "social", "email": "gestion.social.demo@sgspe.test", "displayName": "Gestión social (demo)", "roles": ["SOCIAL_MANAGER"]}
  ],
  "collections": [
    {
      "object": "locality",
      "match": ["name"],
      "as": "admin",
      "records": [
        {
          "key": "loc-huaylla",
          "attributes": {"name": "Caserío Huaylla Alto", "locality_type": "CASERIO", "administrative_unit": "@au-distrito"},
          "geometries": {"location": {"point": [1.2, -0.8]}, "boundary": {"square": [1.2, -0.8, 0.6]}},
          "links": {"state_program_locality": ["@prog-juntos"]},
          "children": [{"object": "engagement_participant", "parent": "engagement", "attributes": {"represented_people_count": 1, "attended": true}}],
          "transitions": ["register_held_unplanned"],
          "state": "held",
          "commands": [{"command": "assessment", "attributes": {"assessment_date": "2026-04-15", "basis": "ENTREVISTA"}}],
          "_expect": {"influence_group": "ESTRATEGICO"}
        }
      ]
    }
  ]
}
```

**Llaves de primer nivel** (todas opcionales en cada archivo):
- `anchor`: una sola vez, en `00-base.json`.
- `users`.
- `collections`.

**Valores de los atributos:**
- Un texto que empieza con `@` es una referencia: se reemplaza por el id del registro con esa `key`. Tiene que estar
  definido antes, en un archivo o colección anterior.
- Una llave `<prefijo>_user` con una clave de usuario se expande a `<prefijo>_user_id` y `<prefijo>_user_email`. Por
  ejemplo, `"owner_user": "social"`; `"admin"` es quien corre el script.
- `{"indicator": "KPI-ENG-02"}` se reemplaza por el id del indicador con ese código.
- En un texto, `[[person:@clave]]` se reemplaza por `[[person:<uuid>]]`, la mención que entiende ReportPeople.

**Geometrías** (en km desde el ancla; el cargador las pasa a GeoJSON EPSG:4326):
- `{"point": [x, y]}` da Point.
- `{"line": [[x, y], …]}` da LineString.
- `{"square": [x, y, half]}` da MultiPolygon.
- `{"polygon": [[x, y], …]}` da MultiPolygon; el anillo se cierra solo.

**Colección:**
- `object`: el nombre del objeto en `model.json`.
- `match`: los atributos (ya resueltos) que identifican un registro existente; es la clave natural.
- `as`: la clave del usuario que escribe; por defecto, `admin`.
- `records`: la lista de registros.

**Registro:**
- `key`: única en todo el conjunto.
- `attributes`, `geometries`, `links`, `children`, `transitions`, `state`, `commands`.
- `_expect`: solo para las pruebas; el cargador lo ignora.

**Comandos** (`command`):

| `command` | Objeto | Llamada | Idempotencia |
|---|---|---|---|
| `assessment` | stakeholder | `POST /api/sgspe/stakeholders/{id}/assessments` `{"attributes":…}` | salta si ya hay un `stakeholder_assessment` de ese grupo con esa `assessment_date` |
| `risk_assessment` | social_risk | `POST /api/sgspe/social-risks/{id}/assessments` `{"attributes":…}` | salta si ya hay un `risk_assessment` con esa `assessment_date` y ese `residual` |
| `approve_area` | area_of_influence | `POST /api/sgspe/areas-of-influence/{id}/approve` `{}`, con `If-Match: "<updatedAt>"` | salta si `state == approved` |
| `close_period` | project | `POST /api/sgspe/indicators/{indicatorId}/measurements` `{"project": id, "attributes": {period_start_date, period_end_date}}` | salta si ya hay un `indicator_measurement` con ese indicador, proyecto y periodo; con `"optional": true`, un 4xx avisa y sigue |
| `sections` | deliverable | por cada `section_key: texto`, `PUT` del `deliverable_section` de ese entregable con `content` y `content_origin: HUMANO` | salta la sección si ya tiene `content` |
| `draft` | deliverable | `POST /api/sgspe/deliverables/{id}/drafts` | solo con `--draft`; salta si `draft_generation_status` es `EN COLA`, `EN PROCESO` o `LISTO` |

Todo POST, PUT, transición y vínculo lleva `X-Change-Reason: UTF-8''Carga%20del%20conjunto%20de%20demostraci%C3%B3n`.

Cada comando lleva también una `Idempotency-Key` estable: `demo-<key>-<n>`.

**Orden por registro:** crear, después `children`, `links`, `transitions` y `commands`.

**Reapertura:** una colección con `"reopen": true` lleva registros con solo `key` y `commands`. Cada `key` tiene que estar
definida antes en el mismo `object`. El cargador corre sus comandos sobre ese registro, con el `as` de la colección. Sirve
para dos cosas:
- aprobar las áreas después de cargar sus miembros;
- cerrar periodos sobre `proj` al final.

La Tarea 1 lo implementa y lo prueba con `test_reabrir_una_clave_corre_sus_comandos`. En la Tarea 3 no hay ningún ajuste
que hacer.

**Un registro que ya existe** (por `match`):
- no se actualiza;
- `children`, `links` y `transitions` se saltan;
- si declara `state` y su estado es otro, el cargador falla con `«<key>: state X, expected Y»`;
- `commands` corre siempre, porque cada comando es idempotente por su cuenta.

def geometry(spec, anchor):
    """Una geometría declarada en km desde el ancla, en GeoJSON EPSG:4326."""
    lat0, lon0 = anchor["lat"], anchor["lon"]
    km_per_deg_lon = 111.320 * math.cos(math.radians(lat0))

    def at(x, y):
        return [round(lon0 + x / km_per_deg_lon, 7), round(lat0 + y / KM_PER_DEG_LAT, 7)]

    kind, value = next(iter(spec.items()))
    if kind == "point":
        return {"type": "Point", "coordinates": at(*value)}
    if kind == "line":
        return {"type": "LineString", "coordinates": [at(*p) for p in value]}
    if kind == "square":
        x, y, h = value
        value = [[x - h, y - h], [x + h, y - h], [x + h, y + h], [x - h, y + h]]
    if kind in ("square", "polygon"):
        ring = [at(*p) for p in value]
        if ring[0] != ring[-1]:
            ring.append(ring[0])
        return {"type": "MultiPolygon", "coordinates": [[ring]]}
    raise DatasetError(f"unknown geometry {kind}")
