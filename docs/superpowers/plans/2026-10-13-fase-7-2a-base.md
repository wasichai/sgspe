# SGSPE · Fase 7, plan 7.2a (base de IA y asistente): plan de implementación

> **Para agentes:** SUB-SKILL OBLIGATORIA: usar superpowers:subagent-driven-development (recomendada) o
> superpowers:executing-plans para ejecutar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`) para el
> seguimiento. Cada tarea de código sigue superpowers:test-driven-development: prueba que falla, implementación mínima,
> prueba en verde, commit.

**Goal:** Dejar en `~/IdeaProjects/sgspe` la base de la IA de F7 —el starter de agente de wasichai 1.2.0, la activación por
organización con `GET /api/sgspe/ai/status`, la seudonimización (`Pseudonymizer`, `PseudonymTable`, `RestrictedFields`),
el registro de cada llamada en `ai_interaction` (`Interactions`), los prompts versionados con su manifiesto, el puerto
`StructuredModel` sobre Embabel con su llamada seudonimizada (`ModelCalls`)— y el asistente AI-05 por
`POST /api/sgspe/ai/assistant/questions`, con los cuatro puntos de extensión de wasichai-agent y `POST /api/agent/ask`
cerrado por HTTP.

**Architecture:** Todo vive en `sgspe.ai`, paquete de salida que ningún paquete de dominio importa (`ArchitectureTest`), y
solo él toca `wasichai.agent` y `com.embabel`. La activación y el estado son configuración (`sgspe.ai.*`) más la presencia
de la plataforma de agentes, que `EmbabelGate` deja fuera sin clave. La seudonimización es Kotlin puro y probado; el
asistente corre en proceso (`AgentService.ask`) como la persona, con la pregunta abierta en `AssistantRun`, que viaja en la
autenticación del contexto de Reactor porque wasichai-agent corre las herramientas y los filtros con un contexto nuevo que
solo lleva la autenticación (decisión 1). Las llamadas propias pasan por el puerto `StructuredModel`; las pruebas usan
`FakeModel`, `MockModel` y el modelo guionado de Embabel (`ScriptedLlmOperations`) detrás de `RecordingLlm`.

**Tech Stack:** Kotlin 2.4.20, Spring Boot 4.1.1 (WebFlux con corrutinas), JDK 25, Gradle 9.8.0, `wasichai-bom` 1.2.0 con
`wasichai-spring-boot-starter-agent` (Embabel 1.5.3 por el BOM, proveedor Anthropic); Jackson 3 (`tools.jackson`) en

## Review Focus

Las cinco entradas que la especificación implica y que más pueden morder a quien use esto, cada una con su prueba en la
tarea dueña del código:

1. **Dos preguntas a la vez de la misma persona** (dos pestañas del portal). Cada pregunta tiene su tabla de equivalencias:
   si se mezclaran, una respuesta se restauraría con los nombres de la otra o un marcador quedaría sin restaurar. Se espera
   que cada corrida vea solo su `AssistantRun`. Pruebas: `AssistantRunTest` «dos preguntas no comparten corrida» (Tarea 10)
   y `AssistantAgentTest` «dos preguntas a la vez no comparten tabla» (Tarea 11).
2. **Una herramienta que lee registros de otro objeto que el de su entrada** (`related_records` desde una interacción hacia
   sus participantes) **o su historial** (`record_history`, con el antes y el después de cada cambio). Enmascarar por
   `input.object` dejaría pasar `participant_name`, `phone` y `email`, y el historial devolvería el valor anterior de un campo
   restringido. Se espera el marcador tipado en los dos. Pruebas: `ToolResultsTest` «related_records enmascara por el objeto
   relacionado, no por el de la entrada» y «el historial enmascara el antes y el después de un campo restringido» (Tarea 10).
3. **Ids, fechas y montos dentro de los resultados.** Un UUID cuyo primer tramo son ocho dígitos se parece a un DNI; si se
   enmascara, el modelo ya no puede pedir ese registro. Se espera que los UUID, las fechas ISO, los montos con decimales y los
   números JSON queden intactos. Pruebas: `PseudonymizerTest` «los ids, las fechas y los montos quedan como están» (Tarea 2) y
   `ToolResultsTest` «query_records seudonimiza el texto libre y deja los conteos» (Tarea 10).
4. **Un nombre escrito de otra forma** («ANA EJEMPLO», «Ejemplo, Ána», «ana  ejemplo»). Se espera el mismo marcador de la
   persona en todas sus formas, y que una palabra suelta («Solo», «Flores») no se tome por persona. Pruebas: `PseudonymizerTest`
   «una persona del diccionario lleva el mismo marcador en todas sus formas» y «un nombre de una sola palabra no entra al
   diccionario» (Tarea 2).
5. **El proveedor que falla a mitad de la pregunta, o una corrida que se queda sin margen.** Se espera `503 AI_UNAVAILABLE`
   con `provider` (o `200` con `truncated` y el texto en español) y que la `ai_interaction` quede igual, con los tokens
   gastados (P6), en el acto y no tras los reintentos de Embabel (decisión 18). Pruebas: `AssistantAgentTest` «un proveedor que
   falla queda registrado como fallido», `AssistantRunApiTest` «un proveedor que falla responde 503 y deja su ai_interaction» y
   «una corrida sin margen responde enseguida, truncada y en español, y queda registrada» (Tarea 11), `AiPropertiesTest` «una
   acción fallida no se reintenta dentro de la petición» (Tarea 1) y `ModelCallsTest` «un proveedor que falla responde 503 y deja
   su interacción con lo gastado» (Tarea 7).

```kotlin
package sgspe.ai

import org.springframework.boot.context.properties.ConfigurationProperties
import org.springframework.boot.context.properties.EnableConfigurationProperties
import org.springframework.context.annotation.Configuration

// la configuración de la IA del despliegue (ai-architecture.md §6.2, §10, §11 y §12.1): las organizaciones con la IA activada
// por su slug (ASM-128), el proveedor que queda en ai_interaction (GAP-015), el modelo y la versión del prompt de cada caso por
// su clave en minúsculas, ai-01 a ai-08 (ASM-129, RQ-AI-006), y los límites de una corrida (ASM-131). AI-05 toma su modelo de
// wasichai.agent.model, no de aquí
@ConfigurationProperties("sgspe.ai")
data class AiProperties(
    val enabledOrganizations: List<String> = emptyList(),
    val provider: String = "anthropic",
    val models: Map<String, String> = emptyMap(),
    val prompts: Map<String, String> = emptyMap(),
    val limits: AiLimits = AiLimits()
) {
```

```kotlin
package sgspe.ai

import java.util.UUID

// los tipos de dato personal o restringido que la IA nunca ve en claro (ai-architecture.md §12.2, security.md §7.8 y §7.9).
// dentro de una llamada, lo que el texto nombra va con número ([PERSONA_1]) y PseudonymTable lo restaura o lo pasa a estable;
// el valor de un campo restringido va siempre sin número ([PERSONA], [DOCUMENTO]…): nadie lo restaura (decisión 3 del plan 7.2a)
enum class Marker {
    PERSONA,
    DOCUMENTO,
    TELEFONO,
    CORREO,
    CONTACTO,
    DATO_SENSIBLE,
    CITA;

    // el marcador tipado sin número ni id
    val reserved: String get() = "[$name]"
}

// una persona del diccionario de nombres: una person con sus nombres, como la lee quien pide (o todas, en JOB-07)
data class KnownPerson(
    val id: UUID?,
    val givenNames: String?,
    val surnames: String?
) {
    // cómo vuelve al restaurar la respuesta de AI-05
    val displayName: String
        get() = listOfNotNull(givenNames?.trim()?.ifEmpty { null }, surnames?.trim()?.ifEmpty { null }).joinToString(" ")
}

// un valor restringido que la llamada conoce (los nombres de los participantes de una interacción, el documento de una persona):
// sale con el marcador tipado de su campo, sin número
data class RestrictedValue(
    val kind: Marker,
    val value: String
)

// minúsculas y sin tildes, letra por letra: el texto plegado mide lo mismo que el original, así que una posición en uno es la misma
// en el otro. «ñ» pliega a «n» y «ü» a «u»
internal object Folding {
    private const val FROM = "áàäâãéèëêíìïîóòöôõúùüûñç"
    private const val TO = "aaaaaeeeeiiiiooooouuuunc"
    private val WORD = Regex("""[\p{L}\p{N}]+""")

    fun fold(text: String): String {
        val out = CharArray(text.length)
        for (i in text.indices) {
            val c = text[i].lowercaseChar()
            val at = FROM.indexOf(c)
            out[i] = if (at >= 0) TO[at] else c
        }
        return String(out)
    }

    // las palabras (letras y dígitos) con su posición
    fun words(text: String): List<MatchResult> = WORD.findAll(text).toList()
}

// el diccionario de nombres de una llamada, por palabras plegadas: «Ana Ejemplo», «ANA EJEMPLO», «Ejemplo, Ana» y «Ána Éjemplo»
// son la misma persona. una persona sin nombres o sin apellidos no entra: un nombre de una sola palabra confundiría palabras
// comunes con personas
class NameDictionary(
    people: Collection<KnownPerson>
) {
    private class Entry(
        val words: List<String>,
        val person: KnownPerson
    )

    private val byFirst: Map<String, List<Entry>> =
        people
            .flatMap { person -> variants(person).map { Entry(it, person) } }
            .groupBy { it.words.first() }
            .mapValues { (_, entries) -> entries.sortedByDescending { it.words.size } }

    // las personas nombradas en el texto, sin solaparse: en cada posición, el nombre más largo
    fun matches(text: String): List<Pair<IntRange, KnownPerson>> {
        if (byFirst.isEmpty()) return emptyList()
        val words = Folding.words(Folding.fold(text))
        val found = mutableListOf<Pair<IntRange, KnownPerson>>()
        var i = 0
        while (i < words.size) {
            val entry = byFirst[words[i].value]?.firstOrNull { fits(text, words, i, it.words) }
            if (entry == null) {
                i++
                continue
            }
            val last = words[i + entry.words.size - 1]
            found += (words[i].range.first..last.range.last) to entry.person
            i += entry.words.size
        }
        return found
    }

    private fun fits(
        text: String,
        words: List<MatchResult>,
        start: Int,
        name: List<String>
    ): Boolean {
        if (start + name.size > words.size) return false
        for (k in name.indices) {
            if (words[start + k].value != name[k]) return false
            if (k > 0 && !separator(text.substring(words[start + k - 1].range.last + 1, words[start + k].range.first))) return false
        }
        return true
    }

    companion object {
        val EMPTY = NameDictionary(emptyList())

        // entre dos palabras de un nombre: espacios y a lo sumo una coma («Ejemplo, Ana»)
        private fun separator(gap: String): Boolean = gap.isNotEmpty() && gap.all { it.isWhitespace() || it == ',' } && gap.count { it == ',' } <= 1

        private fun variants(person: KnownPerson): List<List<String>> {
            val given = Folding.words(Folding.fold(person.givenNames.orEmpty())).map { it.value }
            val surnames = Folding.words(Folding.fold(person.surnames.orEmpty())).map { it.value }
            if (given.isEmpty() || surnames.isEmpty()) return emptyList()
            return listOf(given + surnames, surnames + given).distinct()
        }
    }
}

// la seudonimización antes de cada llamada a un modelo (ai-architecture.md §12.2, RQ-AI-009), en Kotlin puro. en este orden de
// preferencia: los valores restringidos conocidos (los de la llamada y los que la tabla ya reservó) con su marcador tipado sin
// número; los correos, los teléfonos y los documentos de identidad por su formato, y las personas del diccionario, con un marcador
// de la llamada que guarda `table`, numerado en el orden del texto. los UUID quedan intactos: son los ids con que el modelo pide un
// registro. nunca lanza con el texto en el mensaje
object Pseudonymizer {
    private val UUID_SPAN = Regex("""[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}""")
    private val EMAIL = Regex("""[\p{L}\p{N}._%+-]+@[\p{L}\p{N}-]+(?:\.[\p{L}\p{N}-]+)*\.\p{L}{2,}""")

    // un celular del Perú (9 dígitos que empiezan con 9, con o sin +51) o un fijo con su código de ciudad
    private val PHONE =
        Regex(
            """(?<![\p{L}\p{N}+])(?:\+?51[\s.-]?)?9\d{2}[\s.-]?\d{3}[\s.-]?\d{3}(?!\d)|(?<![\p{L}\p{N}+])\(?0\d{1,2}\)?[\s.-]?\d{3}[\s.-]?\d{3,4}(?!\d)"""
        )

    // un RUC de persona natural (10…, 15… o 17…, 11 dígitos) o un DNI (8 dígitos), nunca dentro de otra cifra ni de un monto
    private val DOCUMENT = Regex("""(?<![\p{L}\p{N}.,])(?:(?:10|15|17)\d{9}|\d{8})(?![\p{L}\p{N}]|[.,]\d)""")

    private class Candidate(
        val range: IntRange,
        val priority: Int,
        val replace: (PseudonymTable) -> String
    )

    fun pseudonymize(
        text: String,
        names: NameDictionary,
        table: PseudonymTable,
        restricted: Collection<RestrictedValue> = emptyList()
    ): String {
        if (text.isEmpty()) return text
        val protected = UUID_SPAN.findAll(text).map { it.range }.toList()
        val folded = Folding.fold(text)
        val candidates = mutableListOf<Candidate>()
        for (value in (restricted + table.reserved()).filter { distinctive(it.value) }) {
            for (range in occurrences(folded, Folding.fold(value.value.trim()))) candidates += Candidate(range, 0) { value.kind.reserved }
        }
        EMAIL.findAll(text).forEach { m -> candidates += Candidate(m.range, 1) { it.mark(Marker.CORREO, m.value) } }
        PHONE.findAll(text).forEach { m -> candidates += Candidate(m.range, 2) { it.mark(Marker.TELEFONO, m.value) } }
        DOCUMENT.findAll(text).forEach { m -> candidates += Candidate(m.range, 3) { it.mark(Marker.DOCUMENTO, m.value) } }
        names.matches(text).forEach { (range, person) ->
            candidates += Candidate(range, 4) { it.mark(Marker.PERSONA, person.displayName, person.id) }
        }
        val accepted = mutableListOf<Candidate>()
        val order = compareBy<Candidate>({ it.priority }, { it.range.first }, { -(it.range.last - it.range.first) })
        for (candidate in candidates.sortedWith(order)) {
            if (protected.any { overlaps(it, candidate.range) } || accepted.any { overlaps(it.range, candidate.range) }) continue
            accepted += candidate
        }
        if (accepted.isEmpty()) return text
        val out = StringBuilder(text.length)
        var at = 0
        for (candidate in accepted.sortedBy { it.range.first }) {
            out.append(text, at, candidate.range.first).append(candidate.replace(table))
            at = candidate.range.last + 1
        }
        return out.append(text, at, text.length).toString()
    }

    // un valor restringido se busca en el texto libre solo si se distingue: dos palabras o más, seis dígitos o más, o un correo.
    // una palabra sola («Flores») confundiría el texto con un dato, y un UUID es un id, no un dato
    fun distinctive(value: String): Boolean {
        val text = value.trim()
        if (text.isEmpty() || UUID_SPAN.matches(text)) return false
        return text.count { it.isDigit() } >= 6 || '@' in text || Folding.words(text).size >= 2
    }

    // las apariciones de `needle` (plegado) en `folded` que no empiezan ni terminan dentro de una palabra
    private fun occurrences(
        folded: String,
        needle: String
    ): List<IntRange> {
        if (needle.isEmpty()) return emptyList()
        val found = mutableListOf<IntRange>()
        var from = folded.indexOf(needle)
        while (from >= 0) {
            val end = from + needle.length
            val before = from == 0 || !folded[from - 1].isLetterOrDigit()
            val after = end == folded.length || !folded[end].isLetterOrDigit()
            if (before && after) found += from until end
            from = folded.indexOf(needle, from + 1)
        }
        return found
    }

    private fun overlaps(
        a: IntRange,
        b: IntRange
    ): Boolean = a.first <= b.last && b.first <= a.last
}
```

```kotlin
package sgspe.ai

import java.util.EnumMap
import java.util.UUID

// las equivalencias de una llamada (ai-architecture.md §12.2): cada dato que el texto nombra con su marcador de la llamada
// ([PERSONA_1], [TELEFONO_1]), el mismo para el mismo dato (una persona por su id, lo demás por su valor plegado), y los valores
// restringidos que ya se enmascararon, reservados para el texto libre que siga. vive solo en memoria: nunca se guarda, se
// registra ni se escribe en un log, y su toString no dice nada. las herramientas del asistente la usan desde los hilos de Embabel,
// por eso sincroniza
class PseudonymTable {
    private class Entry(
        val marker: String,
        val value: String,
        val personId: UUID?
    )

    private val byKey = HashMap<String, Entry>()
    private val byMarker = HashMap<String, Entry>()
    private val counters = EnumMap<Marker, Int>(Marker::class.java)
    private val reservedValues = LinkedHashMap<String, RestrictedValue>()

    @Synchronized
    fun mark(
        kind: Marker,
        value: String,
        personId: UUID? = null
    ): String {
        val key = if (personId != null) "${kind.name}:$personId" else "${kind.name}:${Folding.fold(value.trim())}"
        byKey[key]?.let { return it.marker }
        val number = (counters[kind] ?: 0) + 1
        counters[kind] = number
        val entry = Entry("[${kind.name}_$number]", value, personId)
        byKey[key] = entry
        byMarker[entry.marker] = entry
        return entry.marker
    }

    // un valor restringido ya enmascarado: si se distingue, se enmascara también en el texto que siga (decisión 3 del plan 7.2a)
    @Synchronized
    fun reserve(
        kind: Marker,
        value: String
    ) {
        if (Pseudonymizer.distinctive(value)) reservedValues.putIfAbsent(Folding.fold(value.trim()), RestrictedValue(kind, value.trim()))
    }

    @Synchronized
    fun reserved(): List<RestrictedValue> = reservedValues.values.toList()

    // la respuesta de AI-05: cada marcador de la llamada vuelve a su valor; los reservados y los que la tabla no conoce quedan
    @Synchronized
    fun restore(text: String): String = MARKER.replace(text) { byMarker[it.value]?.value ?: it.value }

    // lo que se guarda (7.2b): una persona registrada a [PERSONA:<id>]; las demás, y lo detectado por formato, a su marcador sin
    // número ni valor ([PERSONA], [DOCUMENTO], [TELEFONO], [CORREO])
    @Synchronized
    fun stable(text: String): String =
        MARKER.replace(text) { match ->
            val person = byMarker[match.value]?.personId
            if (person != null) "[PERSONA:$person]" else "[${match.groupValues[1]}]"
        }

    override fun toString(): String = "PseudonymTable(${byMarker.size} marcadores)"

    companion object {
        private val MARKER = Regex("""\[(PERSONA|DOCUMENTO|TELEFONO|CORREO|CONTACTO|DATO_SENSIBLE|CITA)_\d+]""")
    }
}
```

```kotlin
import org.springframework.stereotype.Component
import java.util.concurrent.ConcurrentHashMap

// un prompt armado con la versión en uso de su caso: lo que sale hacia el modelo, ya seudonimizado. su toString no lleva el texto
data class RenderedPrompt(
    val id: String,
    val version: String,
    // la clase de salida que declara la cabecera
    val output: String,
    val text: String
) {
    // lo que queda en ai_interaction.prompt_version (ai-architecture.md §9.2)
    val reference: String get() = "$id@$version"

    override fun toString(): String = "RenderedPrompt($reference)"
}

// una versión de un prompt: src/main/resources/sgspe/ai/prompts/<id>/<versión>.md con su cabecera (ai-architecture.md §10)
data class PromptFile(
    val id: String,
    val version: String,
    val useCase: String,
    val output: String,
    val language: String,
    val body: String
) {
    companion object {
        private val KEYS = listOf("id", "version", "use_case", "output", "language")

        // «---», las cinco claves «clave: valor» en ese orden, «---» y el cuerpo. la cabecera tiene que ser la de su ruta, en
        // español y del caso de su id
        fun parse(
            id: String,
            version: String,
            content: String
        ): PromptFile {
            val lines = content.replace("\r\n", "\n").split("\n")
            check(lines.firstOrNull() == "---") { "el prompt $id@$version no empieza con su cabecera" }
            val end = lines.drop(1).indexOf("---").takeIf { it >= 0 }?.plus(1) ?: error("el prompt $id@$version no cierra su cabecera")
            val header = lines.subList(1, end).associate { it.substringBefore(":").trim() to it.substringAfter(":", "").trim() }
            check(header.keys.toList() == KEYS) { "la cabecera del prompt $id@$version declara ${header.keys}; se esperan $KEYS" }
            check(header["id"] == id && header["version"] == version) { "la cabecera del prompt $id@$version no es la de su ruta" }
            check(AiProperties.key(header.getValue("use_case")) == id) { "el prompt $id@$version es de otro caso" }
            check(header["language"] == "es") { "el prompt $id@$version no está en español" }
            check(header.getValue("output").isNotEmpty()) { "el prompt $id@$version no declara su salida" }
            return PromptFile(
                id,
                version,
                header.getValue("use_case"),
                header.getValue("output"),
                header.getValue("language"),
                lines.drop(end + 1).joinToString("\n").trim()
            )
        }
    }
}

// los prompts versionados (ai-architecture.md §10, RQ-AI-006): la versión en uso de cada caso sale de sgspe.ai.prompts, así que
// volver atrás es un cambio de configuración; las configuradas se cargan al arrancar y una que falta impide arrancar. una versión
// publicada no cambia: PromptManifestTest compara su SHA-256 con prompts/manifest.json
@Component
class Prompts(
    private val properties: AiProperties
) {
    private val loaded = ConcurrentHashMap<String, PromptFile>()

    init {
        properties.prompts.forEach { (useCase, version) -> load(AiProperties.key(useCase), version) }
    }

    fun reference(useCase: String): String = "${AiProperties.key(useCase)}@${properties.promptVersion(useCase)}"

    // el prompt en uso del caso con sus variables: cada {{nombre}} del cuerpo, una sola pasada (un valor con llaves no se vuelve
    // a expandir); una variable que falta o que sobra es un error del código, nunca un prompt a medias
    fun render(
        useCase: String,
        variables: Map<String, String>
    ): RenderedPrompt {
        val id = AiProperties.key(useCase)
        val version = properties.promptVersion(useCase)
        val file = load(id, version)
        return RenderedPrompt(id, version, file.output, fill(file.body, variables, "$id@$version"))
    }

    fun load(
        id: String,
        version: String
    ): PromptFile =
        loaded.getOrPut("$id@$version") {
            val path = "$ROOT/$id/$version.md"
            val content =
                Prompts::class.java.classLoader
                    .getResourceAsStream(path)
                    ?.use { String(it.readAllBytes(), Charsets.UTF_8) }
                    ?: error("falta el prompt $path")
            PromptFile.parse(id, version, content)
        }

    companion object {
        const val ROOT = "sgspe/ai/prompts"
        private val PLACEHOLDER = Regex("""\{\{(\w+)}}""")

        fun fill(
            body: String,
            variables: Map<String, String>,
            reference: String
        ): String {
            val used = PLACEHOLDER.findAll(body).map { it.groupValues[1] }.toSet()
            check(used == variables.keys) { "el prompt $reference usa $used y recibió ${variables.keys}" }
            return PLACEHOLDER.replace(body) { variables.getValue(it.groupValues[1]) }
        }
    }
}
```

```kotlin
package sgspe.ai

import org.springframework.stereotype.Component
import sgspe.common.Callers
import sgspe.common.Records
import wasichai.core.identity.AuthenticatedUser
import java.math.BigDecimal
import java.time.Instant
import java.time.temporal.ChronoUnit
import java.util.UUID

// lo que se registra de una llamada a un modelo (ai-architecture.md §9.2, RF-AIK-009, RQ-AUD-003): una referencia a la entrada,
// nunca su contenido; un resumen sin datos personales; el modelo, la versión del prompt, los tokens y la latencia
data class InteractionEntry(
    val useCase: String,
    val model: String,
    val promptVersion: String,
    val startedAt: Instant,
    val inputReference: String?,
    val outputSummary: String,
    val inputTokens: Int?,
    val outputTokens: Int?,
    val latencyMs: Long,
    val confidence: BigDecimal? = null,
    val project: UUID? = null,
    val modelVersion: String? = null
)

// quien registra las llamadas: Interactions en la app; RecordedInteractions en las pruebas unitarias
fun interface InteractionLog {
    suspend fun record(entry: InteractionEntry): UUID
}

// una ai_interaction por llamada, escrita con Records (RecordService con la marca SgspeWrite) como la persona que pidió la llamada,
// o como la plataforma dentro de Records.asPlatform: sin persona, requested_by_* vacíos y run_by_platform verdadero (lo escribe
// sgspe.ai, que es su único escritor). el objeto es apiOnly y appendOnly: la API genérica no lo escribe y nadie lo cambia después.
// una cuenta de servicio no pide llamadas a la IA (403 PERSON_REQUIRED, decisión 8 del plan 7.2a)
@Component
class Interactions(
    private val records: Records,
    private val callers: Callers,
    private val properties: AiProperties
) : InteractionLog {
    override suspend fun record(entry: InteractionEntry): UUID {
        val requester = callers.userOrNull()
        if (requester?.serviceAccount != null) throw AiErrors.personRequired()
        val created = records.create(OBJECT, attributes(entry, properties.provider, requester), "registro de la llamada a la IA (${entry.useCase})")
        return UUID.fromString(created.id)
    }

    companion object {
        const val OBJECT = "ai_interaction"

        fun attributes(
            entry: InteractionEntry,
            provider: String,
            requester: AuthenticatedUser?
        ): Map<String, Any?> =
            mapOf(
                "use_case" to entry.useCase,
                "provider" to provider,
                "model" to entry.model,
                "model_version" to entry.modelVersion,
                "prompt_version" to entry.promptVersion,
                "started_at" to entry.startedAt.truncatedTo(ChronoUnit.SECONDS).toString(),
                "input_reference" to entry.inputReference,
                "output_summary" to entry.outputSummary,
                "input_tokens" to entry.inputTokens,
                "output_tokens" to entry.outputTokens,
                "latency_ms" to entry.latencyMs.coerceIn(0, Int.MAX_VALUE.toLong()).toInt(),
                "confidence" to entry.confidence,
                "project" to entry.project?.toString(),
                "requested_by_user_id" to requester?.userId?.toString(),
                "requested_by_user_email" to requester?.email,
                "run_by_platform" to (requester == null)
            ).filterValues { it != null }
    }
}
```

```kotlin
import com.embabel.agent.test.integration.ScriptedLlmOperations
import com.embabel.chat.Message
import com.embabel.common.ai.model.LlmMetadata
import com.embabel.common.ai.model.LlmOptions
import com.embabel.common.core.thinking.ThinkingResponse
import org.springframework.boot.test.context.TestConfiguration
import org.springframework.context.annotation.Bean
import org.springframework.context.annotation.Primary
import java.time.Duration
import java.time.Instant
import java.util.concurrent.atomic.AtomicInteger

// el modelo de las pruebas que llegan hasta Embabel (el StubModel de ai-architecture.md §15): ScriptedLlmOperations de Embabel
// 1.5.3, que viene en su jar principal, detrás de un grabador que cuenta las llamadas, anota los tokens que informaría un
// proveedor (ScriptedLlmOperations no anota ninguno) y puede fallar como uno, después de anotarlos. la plataforma resuelve
// LlmOperations una vez al arrancar y un guion se gasta: en una prueba de integración el bean es un conmutador y cada prueba
// cuelga un guion nuevo con fresh(). como AgentExtensionsTest y AgentEmbabelTest de wasichai 1.2.0
class RecordingLlm : LlmOperations {
    @Volatile
    var script: ScriptedLlmOperations = ScriptedLlmOperations()
        private set

    val calls = AtomicInteger()

    @Volatile
    var failure: RuntimeException? = null

    fun fresh(): ScriptedLlmOperations {
        script = ScriptedLlmOperations()
        calls.set(0)
        failure = null
        return script
    }

    private fun book(process: AgentProcess) {
        calls.incrementAndGet()
        process.recordLlmInvocation(
            LlmInvocation(LlmMetadata.create(MODEL, "anthropic"), Usage(INPUT, OUTPUT, null), "sgspe", Instant.now(), Duration.ZERO)
        )
        failure?.let { throw it }
    }

    override fun supportsThinking(options: LlmOptions): Boolean = script.supportsThinking(options)

    override fun <O> createObject(
        messages: List<Message>,
        interaction: LlmInteraction,
        outputClass: Class<O>,
        agentProcess: AgentProcess,
        action: Action?
    ): O {
        book(agentProcess)
        return script.createObject(messages, interaction, outputClass, agentProcess, action)
```

```kotlin
package sgspe.ai

// el puerto propio hacia el modelo (ai-architecture.md §6.2 y §15, especificación de F7 §2.2.5): recibe el prompt ya seudonimizado
// con su versión, el modelo y el tope de tokens, y devuelve la salida tipada con los tokens que informó el proveedor.
// EmbabelStructuredModel lo implementa sobre la plataforma de agentes; FakeModel, MockModel y FailingModel lo sustituyen en las
// pruebas
interface StructuredModel {
    suspend fun <T : Any> complete(request: ModelRequest<T>): ModelResult<T>
}

data class ModelRequest<T : Any>(
    val useCase: String,
    val model: String,
    val prompt: RenderedPrompt,
    val outputClass: Class<T>,
    val maxOutputTokens: Int,
    // instrucciones de sistema opcionales; el prompt versionado lleva las suyas en su texto
    val system: String? = null
)

data class ModelResult<T : Any>(
    val output: T,
    // el modelo que informó el proveedor (varios, separados por comas, si hubo más de uno)
    val model: String,
    val inputTokens: Int?,
    val outputTokens: Int?
)

// la llamada no dio salida: el proveedor no está o falló (UNAVAILABLE, 503) o se quedó sin margen (TRUNCATED, 502). lleva los
// tokens que se gastaron, para su ai_interaction. su mensaje es solo el motivo, nunca un texto del proveedor ni del prompt
class StructuredModelException(
    val reason: Reason,
    val inputTokens: Int? = null,
    val outputTokens: Int? = null,
    cause: Throwable? = null
) : RuntimeException(reason.name, cause) {
    enum class Reason { UNAVAILABLE, TRUNCATED }
}
```

```kotlin
package sgspe.ai

import com.embabel.agent.api.common.ExecutingOperationContext
import com.embabel.agent.api.dsl.agent
import com.embabel.agent.core.AgentPlatform
import com.embabel.agent.core.AgentProcess
import com.embabel.agent.core.Budget
import com.embabel.agent.core.ProcessOptions
import com.embabel.agent.spi.loop.MaxIterationsExceededException
import com.embabel.common.ai.model.LlmOptions
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import org.springframework.beans.factory.ObjectProvider
import org.springframework.stereotype.Component

// StructuredModel sobre la plataforma de agentes de Embabel 1.5.3 (ai-architecture.md §6.2): un proceso sin acciones por
// llamada, como el Ai que Embabel inyecta (InfrastructureInjectionConfiguration), para leer de él los tokens de la llamada
// (llmInvocations). la llamada bloquea, así que corre en Dispatchers.IO, como en wasichai-agent. sin clave no hay plataforma
// (EmbabelGate): UNAVAILABLE
@Component
class EmbabelStructuredModel(
    private val platform: ObjectProvider<AgentPlatform>
) : StructuredModel {
    override suspend fun <T : Any> complete(request: ModelRequest<T>): ModelResult<T> {
        val agentPlatform = platform.ifAvailable ?: throw StructuredModelException(StructuredModelException.Reason.UNAVAILABLE)
        return withContext(Dispatchers.IO) { call(agentPlatform, request) }
    }

    companion object {
        private const val NAME = "sgspe-structured-model"
        private val PLACEHOLDER = agent(name = NAME, description = "Una llamada de salida estructurada de sgspe.ai, sin acciones") {}

        fun <T : Any> call(
            platform: AgentPlatform,
            request: ModelRequest<T>
        ): ModelResult<T> {
            val process = platform.createAgentProcess(PLACEHOLDER, ProcessOptions(budget = Budget(actions = 1)), emptyMap())
            val output =
                try {
                    val runner =
                        ExecutingOperationContext(NAME, process)
                            .ai()
                            .withLlm(LlmOptions.withModel(request.model).withMaxTokens(request.maxOutputTokens))
                    (request.system?.let { runner.withSystemPrompt(it) } ?: runner).createObject(request.prompt.text, request.outputClass)
                } catch (e: MaxIterationsExceededException) {
                    throw failure(StructuredModelException.Reason.TRUNCATED, process, e)
                } catch (e: Exception) {
                    throw failure(StructuredModelException.Reason.UNAVAILABLE, process, e)
                }
            val calls = process.llmInvocations
            return ModelResult(
                output,
                calls.map { it.llmMetadata.name }.distinct().joinToString(",").ifEmpty { request.model },
                calls.takeIf { it.isNotEmpty() }?.sumOf { it.usage.promptTokens ?: 0 },
                calls.takeIf { it.isNotEmpty() }?.sumOf { it.usage.completionTokens ?: 0 }
            )
        }

        private fun failure(
            reason: StructuredModelException.Reason,
            process: AgentProcess,
            cause: Exception
        ): StructuredModelException {
            val calls = process.llmInvocations
            return StructuredModelException(
                reason,
                calls.takeIf { it.isNotEmpty() }?.sumOf { it.usage.promptTokens ?: 0 },
                calls.takeIf { it.isNotEmpty() }?.sumOf { it.usage.completionTokens ?: 0 },
                cause
            )
        }
    }
}
```

```kotlin
// los dobles del puerto StructuredModel (ai-architecture.md §15). FakeModel: salidas fijas según la entrada, sin Embabel.
// MockModel: anota todo lo que se le envía (lo que saldría hacia el proveedor) y contesta con otro doble. FailingModel: un
// proveedor que falla como `reason` después de gastar tokens. escritos a mano: el proyecto usa Mockito, no MockK (decisión 11)
class FakeModel(
    private val answer: (ModelRequest<*>) -> Any
) : StructuredModel {
    override suspend fun <T : Any> complete(request: ModelRequest<T>): ModelResult<T> =
        ModelResult(request.outputClass.cast(answer(request)), request.model, INPUT, OUTPUT)

    companion object {
        const val INPUT = 120
        const val OUTPUT = 30
    }
}

class MockModel(
    private val then: StructuredModel
) : StructuredModel {
    val sent = CopyOnWriteArrayList<ModelRequest<*>>()

    override suspend fun <T : Any> complete(request: ModelRequest<T>): ModelResult<T> {
        sent += request
        return then.complete(request)
    }
}

class FailingModel(
    private val reason: StructuredModelException.Reason
) : StructuredModel {
    override suspend fun <T : Any> complete(request: ModelRequest<T>): ModelResult<T> = throw StructuredModelException(reason, 50, 0)
}
```

```kotlin
package sgspe.ai

import org.springframework.stereotype.Component
import java.time.Clock
import java.time.Duration
import java.time.Instant
import java.util.UUID

// una llamada de un caso a su modelo: las variables del prompt (texto en claro, como lo lee quien pide), el diccionario de nombres
// y los valores restringidos que la llamada conoce, la clase de la salida, la referencia de la entrada y el resumen de la salida
// para ai_interaction (sin datos personales). inputField es el campo del 422 (target en POST /ai/runs)
data class ModelCall<T : Any>(
    val useCase: String,
    val variables: Map<String, String>,
    val names: NameDictionary,
    val outputClass: Class<T>,
    val inputReference: String,
    val project: UUID? = null,
    val restricted: List<RestrictedValue> = emptyList(),
    val inputField: String = "target",
    val summary: (T) -> String
)

data class ModelCallResult<T : Any>(
    val output: T,
    // la tabla de la llamada: 7.2b pasa la salida a marcadores estables con ella antes de guardar
    val table: PseudonymTable,
    // el prompt tal como salió: CitationCheck (7.2b) busca la cita en su texto
    val sent: RenderedPrompt,
    val interaction: UUID
)

// la llamada de un caso a su modelo (ai-architecture.md §6.1, §6.2 y §9.2), la base de cada agente de 7.2b: la entrada pasa el
// límite de tamaño (422 AI_INPUT_TOO_LARGE antes de llamar, sin interacción), se seudonimiza con una tabla nueva, se arma con la
// versión en uso del prompt del caso y se envía con su modelo y su tope de tokens. con éxito o sin él queda su ai_interaction, con
// lo gastado (P6); después, 503 AI_UNAVAILABLE si el proveedor falló o 502 AI_RUN_TRUNCATED si se quedó sin margen. lo que sale
// hacia el modelo es solo el prompt seudonimizado
@Component
class ModelCalls(
    private val model: StructuredModel,
    private val prompts: Prompts,
    private val interactions: InteractionLog,
    private val properties: AiProperties,
    private val clock: Clock
) {
    suspend fun <T : Any> call(call: ModelCall<T>): ModelCallResult<T> {
        val limit = properties.limits.inputChars
        if (call.variables.values.sumOf { it.length } > limit) throw AiErrors.inputTooLarge(call.inputField, limit)
        val table = PseudonymTable()
        val sent = prompts.render(call.useCase, call.variables.mapValues { (_, text) -> Pseudonymizer.pseudonymize(text, call.names, table, call.restricted) })
        val modelName = properties.modelFor(call.useCase)
        val started = clock.instant()
        val result =
            try {
                model.complete(ModelRequest(call.useCase, modelName, sent, call.outputClass, properties.limits.outputTokens))
            } catch (e: StructuredModelException) {
                record(call, sent, modelName, started, e.inputTokens, e.outputTokens, failureSummary(e.reason))
                throw if (e.reason == StructuredModelException.Reason.TRUNCATED) AiErrors.truncated() else AiErrors.unavailable(AiErrors.PROVIDER)
            }
        val interaction = record(call, sent, result.model, started, result.inputTokens, result.outputTokens, call.summary(result.output))
        return ModelCallResult(result.output, table, sent, interaction)
    }

    private suspend fun record(
        call: ModelCall<*>,
        sent: RenderedPrompt,
        model: String,
        started: Instant,
        inputTokens: Int?,
        outputTokens: Int?,
        summary: String
    ): UUID =
        interactions.record(
            InteractionEntry(
                useCase = call.useCase,
                model = model,
                promptVersion = sent.reference,
                startedAt = started,
                inputReference = call.inputReference,
                outputSummary = summary,
                inputTokens = inputTokens,
                outputTokens = outputTokens,
                latencyMs = Duration.between(started, clock.instant()).toMillis(),
                project = call.project
            )
        )

    companion object {
        fun failureSummary(reason: StructuredModelException.Reason): String =
            when (reason) {
                StructuredModelException.Reason.UNAVAILABLE -> "Llamada fallida: el proveedor no respondió"
                StructuredModelException.Reason.TRUNCATED -> "Llamada truncada: sin margen de tokens o de acciones"
            }
    }
}
```

```kotlin
interface AiUseCaseOffer {
    val useCase: String

    suspend fun offered(user: AuthenticatedUser): Boolean
}

// AI-05, el asistente (ASM-130, ai-architecture.md §8): toda persona con CREATE sobre ai_interaction; una cuenta de servicio, no.
// en un tenant que todavía no tiene el modelo de F7, ai_interaction no existe y el asistente no se ofrece
@Component
class AssistantUseCase(
    private val permissions: Permissions
) : AiUseCaseOffer {
    override val useCase: String = USE_CASE

    override suspend fun offered(user: AuthenticatedUser): Boolean = decide(user.serviceAccount != null, canCreateInteraction(user)) == null

    // 403 si no puede preguntar: PERSON_REQUIRED a una cuenta de servicio, o el permiso que le falta
    suspend fun require(user: AuthenticatedUser) {
        decide(user.serviceAccount != null, canCreateInteraction(user))?.let { throw it }
    }

    private suspend fun canCreateInteraction(user: AuthenticatedUser): Boolean =
        try {
            permissions.has(user, Actions.CREATE, Interactions.OBJECT)
        } catch (_: NotFoundException) {
            false
        }

    companion object {
        const val USE_CASE = "AI-05"

        fun decide(
            serviceAccount: Boolean,
            canCreate: Boolean
        ): WasichaiException? =
            when {
                serviceAccount -> AiErrors.personRequired()
                !canCreate -> ForbiddenException("El asistente exige permiso de creación sobre ai_interaction")
                else -> null
            }
    }
}
```

```kotlin
package sgspe.ai

import org.springframework.web.bind.annotation.GetMapping
import org.springframework.web.bind.annotation.RequestMapping
import org.springframework.web.bind.annotation.RestController
import org.springframework.web.server.ServerWebExchange
import sgspe.common.Callers
import sgspe.common.StrictQuery
import wasichai.core.identity.AuthenticatedUser

data class AiStatusResponse(
    val enabled: Boolean,
    val providerAvailable: Boolean,
    val useCases: List<String>
)

// GET /api/sgspe/ai/status (api.md §4.14, ai-architecture.md §12.1): responde siempre a toda persona autenticada. enabled dice si
// su organización tiene la IA activada; providerAvailable, si hay proveedor; useCases, los casos que le ofrecen sus permisos:
// vacío si la organización no tiene la IA y, con ella, los mismos haya o no proveedor (el portal dice por qué no se usan)
@RestController
@RequestMapping("/api/sgspe/ai/status")
class AiStatus(
    private val callers: Callers,
    private val activation: AiActivation,
    private val offers: List<AiUseCaseOffer>
) {
    @GetMapping
    suspend fun status(exchange: ServerWebExchange): AiStatusResponse {
        StrictQuery.requireOnly(exchange.request.queryParams, emptySet())
        return compose(activation.organizationEnabled(), activation.providerAvailable(), callers.require(), offers)
    }

    companion object {
        suspend fun compose(
            enabled: Boolean,
            providerAvailable: Boolean,
            user: AuthenticatedUser,
            offers: List<AiUseCaseOffer>
        ): AiStatusResponse =
            AiStatusResponse(
                enabled,
                providerAvailable,
                if (enabled) offers.filter { it.offered(user) }.map { it.useCase }.sorted() else emptyList()
            )
    }
}
```

```kotlin
            override fun messageWriters(): List<HttpMessageWriter<*>> = codecs.writers

            override fun viewResolvers(): List<ViewResolver> = emptyList()
        }

    override fun filter(
        exchange: ServerWebExchange,
        chain: WebFilterChain
    ): Mono<Void> {
        if (!closed(exchange.request)) return chain.filter(exchange)
        val problem = handler.handleWasichai(ForbiddenException(MESSAGE))
        if (problem.instance == null) problem.instance = URI.create(exchange.request.path.value())
        return ServerResponse
            .status(problem.status)
            .contentType(MediaType.APPLICATION_PROBLEM_JSON)
            .bodyValue(problem)
            .flatMap { it.writeTo(exchange, context) }
    }

    companion object {
        // después de la cadena de seguridad (-100), de IssueDocumentFilter (-99) y de RequestMemoFilter (-98)
        const val ORDER = -97
        const val MESSAGE = "El asistente se usa por POST /api/sgspe/ai/assistant/questions, que activa, seudonimiza y registra cada pregunta"

        // la ruta de AgentController.ask, con el analizador del mapeo de WebFlux: sin parámetros de ruta, decodificada
        private val ASK = PathPatternParser.defaultInstance.parse("/api/agent/ask")

        fun closed(request: ServerHttpRequest): Boolean = ASK.matches(request.path.pathWithinApplication())
    }
}
```

```kotlin
package sgspe.ai
```

```kotlin
import kotlinx.coroutines.currentCoroutineContext
import kotlinx.coroutines.reactive.awaitFirstOrNull
import kotlinx.coroutines.reactor.ReactorContext
import kotlinx.coroutines.reactor.asCoroutineContext

import org.springframework.security.core.context.ReactiveSecurityContextHolder

import java.time.Instant
```

```kotlin
// una pregunta al asistente (AI-05, ai-architecture.md §8): su tabla de equivalencias, el diccionario de nombres de quien pregunta,
// la versión del prompt, cuándo empezó y la ai_interaction que la registra (la escribe InteractionRunListener). nunca se guarda ni
// se registra, y su toString no dice nada
class AssistantRun(
    val question: String,
    val names: NameDictionary,
    val promptVersion: String,
    val startedAt: Instant,
    val table: PseudonymTable = PseudonymTable()
) {
    @Volatile
    var interaction: UUID? = null

    override fun toString(): String = "AssistantRun($promptVersion)"

    companion object {
        // la pregunta en curso, o null fuera de una: en la corrutina de la petición y en los hilos de Embabel por igual, porque
        // viaja en la autenticación que AgentService captura (decisión 1 del plan 7.2a)
        suspend fun current(): AssistantRun? = (ReactiveSecurityContextHolder.getContext().awaitFirstOrNull()?.authentication as? QuestionAuthentication)?.run

        // corre `block` con la pregunta en la autenticación del contexto de Reactor, que conserva todo lo demás. wasichai-agent corre
        // las herramientas y los filtros con un contexto nuevo que solo lleva la autenticación capturada por AgentService.caller():
        // un elemento del contexto de la corrutina no llegaría al filtro de resultados
        suspend fun <T> bind(
            run: AssistantRun,
            block: suspend () -> T
        ): T {
            val authentication =
                ReactiveSecurityContextHolder.getContext().awaitFirstOrNull()?.authentication
                    ?: throw UnauthorizedException("Authentication required")
            val reactor = currentCoroutineContext()[ReactorContext]?.context ?: Context.empty()
            val tagged = reactor.putAll(ReactiveSecurityContextHolder.withAuthentication(QuestionAuthentication(authentication, run)).readOnly())
            return withContext(tagged.asCoroutineContext()) { block() }
        }
    }
}

// la autenticación de quien pregunta, tal cual (el principal sigue siendo su Jwt: CurrentUser y los permisos no cambian), con la
// pregunta en curso. solo AssistantRun la pone en el contexto (ArchitectureTest)
class QuestionAuthentication(
    private val delegate: Authentication,
    val run: AssistantRun
) : Authentication by delegate {
    override fun toString(): String = "QuestionAuthentication(${delegate.name})"
}
```

```kotlin
package sgspe.ai

import org.springframework.stereotype.Component
import sgspe.common.Records
import sgspe.common.Values

// el diccionario de nombres de quien pregunta (especificación de F7 §2.2.4, ai-architecture.md §12.2): las person que lee, con
// Records y como la persona, con sus nombres y apellidos. sin READ sobre person, o sin esos campos (security.md §7.9), queda vacío:
// AI-05 no exige leerlos, y lo que la persona no lee las herramientas tampoco lo devuelven
@Component
class PersonNames(
    private val records: Records
) {
    suspend fun readable(): NameDictionary {
        val people =
            try {
                records.all(PERSON)
            } catch (_: ForbiddenException) {
                return NameDictionary.EMPTY
            } catch (_: NotFoundException) {
                return NameDictionary.EMPTY
            }
        return of(people.map { it.id to it.attributes })
    }

    companion object {
        private const val PERSON = "person"

        // (id, atributos) de cada person leída
        fun of(rows: List<Pair<String, Map<String, Any?>>>): NameDictionary =
            NameDictionary(
                rows.map { (id, attributes) ->
                    KnownPerson(runCatching { UUID.fromString(id) }.getOrNull(), Values.text(attributes["given_names"]), Values.text(attributes["surnames"]))
                }
            )
    }
}
```

```kotlin
// restringido del objeto leído, con su marcador tipado sin número (RestrictedFields), y todo texto seudonimizado con la tabla y el
// diccionario de la pregunta. el objeto leído es el relatedObject del resultado (related_records), si no su object (query_records,
// count_records, record_history…) o, si no trae ninguno, el object de la entrada (get_record) (decisión 2 del plan 7.2a). se
// enmascaran los atributos de un registro y el antes y el después de un cambio del historial. un valor restringido que se distingue
// queda reservado en la tabla y se enmascara también en el texto libre que siga. un texto que no es un objeto ni una lista json (el
// resumen de un paso, un error) solo se seudonimiza. los números, los booleanos y las claves no se tocan
object ToolResults {
    private const val ATTRIBUTES = "attributes"
    private val json = JsonMapper.builder().build()

    fun screen(
        input: Map<String, Any?>,
        text: String,
        names: NameDictionary,
        table: PseudonymTable
    ): String {
        val parsed = parse(text) ?: return Pseudonymizer.pseudonymize(text, names, table)
        val masked = mask(parsed, RestrictedFields.of(objectOf(parsed, input)), table, null)
        return json.writeValueAsString(pseudonymized(masked, names, table))
    }

    fun objectOf(
        parsed: Any?,
        input: Map<String, Any?>
    ): String? {
        val payload = parsed as? Map<*, *>
        return (payload?.get("relatedObject") ?: payload?.get("object") ?: input["object"])?.toString()
    }

    private fun parse(text: String): Any? {
        val start = text.trimStart().firstOrNull()
        if (start != '{' && start != '[') return null
        return try {
            json.readValue(text, Any::class.java)
        } catch (_: JacksonException) {
            null
        }
    }

    // `key` es la clave bajo la que cuelga `node`: los campos de un mapa que cuelga de attributes son los del registro
    private fun mask(
        node: Any?,
        fields: Map<String, Marker>,
        table: PseudonymTable,
        key: String?
    ): Any? =
        when (node) {
            is Map<*, *> -> {
                val change = if ("before" in node || "after" in node) node["field"]?.toString()?.let { fields[it] } else null
                node.entries.associate { (k, v) ->
                    val name = k.toString()
                    val marker =
                        when {
                            key == ATTRIBUTES -> fields[name]
                            change != null && (name == "before" || name == "after") -> change
                            else -> null
                        }
                    name to if (marker != null && v != null) reserve(v, marker, table) else mask(v, fields, table, name)
                }
            }
            is List<*> -> node.map { mask(it, fields, table, key) }
            else -> node
        }

    // el marcador del campo; cada texto del valor queda reservado en la tabla si se distingue
    private fun reserve(
        value: Any,
        marker: Marker,
        table: PseudonymTable
    ): String {
        texts(value).forEach { table.reserve(marker, it) }
        return marker.reserved
    }

    private fun texts(node: Any?): List<String> =
        when (node) {
            is String -> listOf(node)
            is Map<*, *> -> node.values.flatMap { texts(it) }
            is List<*> -> node.flatMap { texts(it) }
            else -> emptyList()
        }

    private fun pseudonymized(
        node: Any?,
        names: NameDictionary,
        table: PseudonymTable
    ): Any? =
        when (node) {
            is String -> Pseudonymizer.pseudonymize(node, names, table)
            is Map<*, *> -> node.entries.associate { (k, v) -> k.toString() to pseudonymized(v, names, table) }
            is List<*> -> node.map { pseudonymized(it, names, table) }
            else -> node
        }
}
```

```kotlin
import wasichai.agent.AgentAnswer
```
```kotlin
import wasichai.agent.AgentProperties
```

```kotlin
// la ai_interaction de cada pregunta al asistente (ai-architecture.md §8 y §9.2, RF-AIK-009): el modelo y los tokens de
// AgentUsage, la latencia desde que AssistantQuestions abrió la pregunta, la versión del prompt de AI-05 y el SHA-256 de la pregunta
// como input_reference, nunca su texto; también en una corrida truncada o fallida. la escribe Interactions como la persona que
// pregunta. si no puede registrar, la pregunta falla: wasichai no responde sin registro. fuera de una pregunta de AssistantQuestions
// (POST /api/agent/ask está cerrado por AgentHttpGate) lanza: nada corre sin su registro. el log, solo el id
@Component
class InteractionRunListener(
    private val interactions: InteractionLog,
    private val agent: ObjectProvider<AgentProperties>,
    private val clock: Clock
) : AgentRunListener {
    override suspend fun onRun(
        caller: AuthenticatedUser,
        question: String,
        answer: AgentAnswer?,
        usage: AgentUsage?,
        error: Throwable?
    ) {
        val run = AssistantRun.current() ?: throw IllegalStateException("una corrida del asistente fuera de POST /api/sgspe/ai/assistant/questions")
        val id = interactions.record(entry(run, answer, usage, error, clock.instant(), agent.ifAvailable?.model))
        run.interaction = id
        LOG.info("AI-05 registrada en ai_interaction {}", id)
    }

    companion object {
        private val LOG = LoggerFactory.getLogger(InteractionRunListener::class.java)
        private const val UNKNOWN_MODEL = "desconocido"

        fun entry(
            run: AssistantRun,
            answer: AgentAnswer?,
            usage: AgentUsage?,
            error: Throwable?,
            now: Instant,
            configuredModel: String?
        ): InteractionEntry =
            InteractionEntry(
                useCase = AssistantUseCase.USE_CASE,
                model = usage?.model ?: configuredModel ?: UNKNOWN_MODEL,
                promptVersion = run.promptVersion,
                startedAt = run.startedAt,
                inputReference = "sha256:${Hashes.sha256(run.question)}",
                outputSummary = summary(answer, error),
                inputTokens = usage?.inputTokens,
                outputTokens = usage?.outputTokens,
                latencyMs = Duration.between(run.startedAt, now).toMillis()
            )

        // sin datos personales: el desenlace, cuántos pasos y qué herramientas
        fun summary(
            answer: AgentAnswer?,
            error: Throwable?
        ): String {
            if (answer == null) return "Corrida fallida (${error?.javaClass?.simpleName ?: "sin causa"}); sin respuesta"
            val tools = answer.steps.map { it.tool }.distinct().joinToString(", ").ifEmpty { "ninguna" }
            val prefix = if (answer.truncated) "Corrida truncada tras ${answer.steps.size} pasos" else "Respuesta con ${answer.steps.size} pasos"
            return "$prefix; herramientas: $tools"
        }
    }
}
```

```kotlin
package sgspe.ai

import org.slf4j.LoggerFactory
import org.springframework.beans.factory.ObjectProvider
import org.springframework.http.HttpStatus
import org.springframework.web.bind.annotation.PostMapping
import org.springframework.web.bind.annotation.RequestBody
import org.springframework.web.bind.annotation.RequestMapping

import org.springframework.web.server.ServerWebExchange
import sgspe.common.Callers
import sgspe.common.RuleException
import sgspe.common.StrictBody
import sgspe.common.StrictQuery
import wasichai.agent.AgentAnswer
import wasichai.agent.AgentFilterException
import wasichai.agent.AgentService
import wasichai.agent.AgentUnavailableException
import wasichai.core.common.ValidationException
import java.time.Clock
import java.util.UUID

data class AssistantStep(
    val tool: String,
    val input: Map<String, Any?>,
    val summary: String
)

data class AssistantAnswer(
    val answer: String,
    val steps: List<AssistantStep>,
    val truncated: Boolean,
    // el id de la ai_interaction que registra la pregunta
    val interaction: String?
)

// POST /api/sgspe/ai/assistant/questions (api.md §4.14, ai-architecture.md §8, ASM-130): AI-05 por el asistente de solo lectura de
// wasichai-agent, en proceso y como quien pregunta. en este orden (decisión 7 del plan 7.2a): el cuerpo (400) y el largo de la
// pregunta (422 AI_INPUT_TOO_LARGE), la activación de la organización (503 AI_UNAVAILABLE organization), la persona y su permiso
// (403), el proveedor (503 AI_UNAVAILABLE provider). después abre la pregunta (AssistantRun: tabla nueva, el diccionario de nombres
// que quien pregunta lee y la hora), seudonimiza la pregunta, la arma con la versión en uso del prompt de AI-05 y llama a
// AgentService.ask con la pregunta en la autenticación. los filtros de sgspe.ai enmascaran y seudonimizan lo que sale hacia el
// modelo y restauran la respuesta; InteractionRunListener la registra. los pasos vuelven restaurados con la misma tabla, y la
// respuesta de una corrida truncada o vacía, en español. el log solo lleva el id de la ai_interaction
@RestController
@RequestMapping("/api/sgspe/ai/assistant/questions")
class AssistantQuestions(
    private val callers: Callers,
    private val activation: AiActivation,
    private val assistant: AssistantUseCase,
    private val names: PersonNames,
    private val prompts: Prompts,
    private val agent: ObjectProvider<AgentService>,
    private val properties: AiProperties,
    private val clock: Clock
) {
    @PostMapping
    suspend fun ask(
        @RequestBody body: Map<String, Any?>,
        exchange: ServerWebExchange
    ): AssistantAnswer {
        StrictQuery.requireOnly(exchange.request.queryParams, emptySet())
        val question = questionOf(body, properties.limits.questionChars)
        val user = callers.require()
        activation.requireOrganization()
        assistant.require(user)
        activation.requireProvider()
        val service = agent.ifAvailable ?: throw AiErrors.unavailable(AiErrors.PROVIDER)
        val dictionary = names.readable()
        val table = PseudonymTable()
        val prompt = prompts.render(AssistantUseCase.USE_CASE, mapOf(QUESTION to Pseudonymizer.pseudonymize(question, dictionary, table)))
        val run = AssistantRun(question, dictionary, prompt.reference, clock.instant(), table)
        val answer =
            try {
                AssistantRun.bind(run) { service.ask(prompt.text) }
            } catch (_: AgentUnavailableException) {
                throw AiErrors.unavailable(AiErrors.PROVIDER)
            } catch (_: AgentFilterException) {
                throw RuleException(HttpStatus.INTERNAL_SERVER_ERROR, FILTER_FAILED)
            }
        LOG.info("AI-05 respondió; ai_interaction {}", run.interaction)
        return response(answer, table, run.interaction)
    }

    companion object {
        private val LOG = LoggerFactory.getLogger(AssistantQuestions::class.java)
        const val QUESTION = "question"
        const val TRUNCATED =
            "Me detuve después de demasiados pasos sin llegar a una respuesta. Pruebe con una pregunta más acotada o nombre el objeto que le interesa."
        const val EMPTY = "No pude armar una respuesta para esa pregunta."

        // la respuesta vacía de WasichaiAgent (wasichai-agent 1.2.0), que llega en inglés
        private const val WASICHAI_EMPTY = "I could not put an answer together for that."
        private const val FILTER_FAILED = "El asistente no pudo preparar los datos para el modelo: no se envió nada"

        // 400 si falta, no es texto, está en blanco o el cuerpo trae otra propiedad; 422 AI_INPUT_TOO_LARGE si pasa el tope
        fun questionOf(
            body: Map<String, Any?>,
            limit: Int
        ): String {
            StrictBody.requireOnly(body, setOf(QUESTION))
            val raw = body[QUESTION]
            if (raw != null && raw !is String) throw ValidationException("Cuerpo inválido", QUESTION, "debe ser un texto")
            val question = (raw as String?)?.trim().orEmpty()
            if (question.isEmpty()) throw ValidationException("Cuerpo inválido", QUESTION, "es obligatoria")
            if (question.length > limit) throw AiErrors.inputTooLarge(QUESTION, limit)
            return question
        }

        fun response(
            answer: AgentAnswer,
            table: PseudonymTable,
            interaction: UUID?
        ): AssistantAnswer =
            AssistantAnswer(
                answer =
                    when {
                        answer.truncated -> TRUNCATED
                        answer.answer == WASICHAI_EMPTY -> EMPTY
                        else -> answer.answer
                    },
                steps = answer.steps.map { step -> AssistantStep(step.tool, step.input.mapValues { restored(it.value, table) }, table.restore(step.summary)) },
                truncated = answer.truncated,
                interaction = interaction?.toString()
            )

        private fun restored(
            node: Any?,
            table: PseudonymTable
        ): Any? =
            when (node) {
                is String -> table.restore(node)
                is Map<*, *> -> node.entries.associate { (k, v) -> k.toString() to restored(v, table) }
                is List<*> -> node.map { restored(it, table) }
                else -> node
            }
    }
}
```
