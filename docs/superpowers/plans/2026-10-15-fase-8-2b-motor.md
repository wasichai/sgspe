# SGSPE · Fase 8, plan 8.2b (motor de entregables y T2): plan de implementación

> **Para agentes:** SUB-SKILL OBLIGATORIA: usar superpowers:subagent-driven-development (recomendada) o
> superpowers:executing-plans para ejecutar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`) para el
> seguimiento. Cada tarea de código sigue superpowers:test-driven-development: prueba que falla, implementación mínima,
> prueba en verde, commit.

**Goal:** Dejar en `~/IdeaProjects/sgspe` el motor de entregables de F8 con T2 (INFORME DE CAMPO Y AVANCE) de punta a
punta salvo los mapas y el PDF reales: el modelo del informe con su JSON canónico y su divulgación INTERNO y EXTERNO
(`sgspe.privacy`), el DOCX sobre la plantilla de la organización (`DocxWriter`, commonmark-java y POI), la subida validada
de plantillas, JOB-05 con candados y retoma de pedidos viejos, el pedido y el estado del borrador, `DeliverableWriteGuard`
y las secciones del tipo al dar de alta, los avisos de WF-H, las descargas con `export_log` y las rutas nativas de
archivos, y la emisión en la petición de la persona con AUT-12. Los mapas y el PDF van detrás de puertos con dobles
(`ReportMaps`, `PdfConverter`; 8.2c trae GeoServer y Gotenberg). Adjuntar los siete archivos del borrador como la
plataforma espera UPS-31 (wasichai/wasichai#111): el plan lo aísla en un puerto (`DraftFiles`) y en un bloque final
separable (Tarea 15) que sube wasichai a la versión que lo resuelva.

**Architecture:** `sgspe.privacy` define el modelo del informe (`ReportModel`, con cada elemento sensible marcado), su forma
canónica con SHA-256 (`CanonicalJson`) y su transformación por nivel (`ReportDisclosure`, `Mentions`, `PersonalDataScan`),
sin depender de nada más que de `common`. `sgspe.deliverable` (paquete nuevo) tiene una clase por tipo (`FieldReportType`)
que ensambla el modelo como la plataforma con lecturas proyectadas a los campos que declara (`ReportSources`); JOB-05
(`DeliverableGenerationJob` y `DraftGeneration`) congela el modelo, lo vuelve a leer, escribe por nivel el DOCX del
borrador y el de la candidata, los convierte con `PdfConverter`, los verifica con PDFBox (`PdfChecks`) y entrega los siete
archivos a `DraftFiles`. Los endpoints (`DeliverableDrafts`, `DeliverableContent`, `DeliverableIssue`,
`DeliverableTemplates`) corren como la persona con la marca de escritura de `Records`; la emisión no genera nada: copia
las candidatas con `FileService.stage` y, en una transacción con el candado del entregable, crea las versiones, escribe
`export_log` y aplica `issue` al final. Los bytes de archivos que un trabajo lee sin persona pasan por un solo lector,
`sgspe.common.StoredFiles` (antes `sgspe.ai.EvidenceFiles`).

## Global Constraints

Las «Restricciones globales» de la especificación, tal cual:

- wasichai `1.2.0` exacto hasta que 8.2b suba a la versión que resuelva la UPS nueva de §2.2.2 (también exacta);
  `@wasichai/*` de la versión que ya usa sgspe-ui, Kotlin `2.4.20`, Spring Boot `4.1.1`, JDK `25`, Gradle `9.8.0`,
  Apache POI `5.5.1` (ya en `build.gradle.kts`), PDFBox en `main` desde F7; español (es-PE) en documentos, comentarios,
  textos fijos de los tipos y `detail`, nombres técnicos en inglés (ADR-0009); valores ENUM en español MAYÚSCULAS sin
  tildes.
- Nunca código bajo el paquete `wasichai`; nunca `RecordStore`, `PhysicalTableRecordStore`, `AuditService` ni
  `ObjectSchemaManager`; `scope` y `privacy` solo dependen de `common`; ningún literal de rol en `src/main/kotlin`;
  ningún paquete de dominio depende de `sgspe.dashboard`, `sgspe.deliverable` ni `sgspe.ai`.
- Nunca `asPlatform` dentro de una petición: el ensamblado y la generación corren solo en JOB-05; pedir borradores,
  emitir, descargar, cerrar periodos, consultar tableros y adoptar sugerencias corren como la persona.
- Ninguna petición llama a Gotenberg ni a GeoServer por un entregable: solo JOB-05 (el proxy WMS de F6 sigue siendo la
  única excepción, y no toca entregables).
- Nada se sirve sin la marca BORRADOR antes de emitir; la versión candidata y el modelo congelado nunca se sirven.
- Gotenberg y GeoServer nunca son públicos; Gotenberg nunca recibe una URL, una ruta ni una opción que venga del cliente
  y no descarga nada de la red.
- En ningún nivel salen el documento de identidad ni los teléfonos de una persona; EXTERNO sale solo en PDF y exige la
  lista de verificación.
- Los logs nunca llevan narrativa, contenido de un entregable ni datos personales: solo ids, códigos de aviso y el id de
  correlación.
- Un tenant que todavía no tiene el modelo de F8 sigue con F7: JOB-05 recorre `Organizations.having("deliverable")` y
  los tableros nuevos preguntan a `TenantModel` por `indicator` antes de leer metas o cifras oficiales.
- Fixtures, plantillas de prueba y textos fijos con datos ficticios (`@sgspe.test`, «Proyecto Ejemplo A», «Comunidad
  Ejemplo», «Persona Ejemplo 1», «Asociación Ejemplo») y topónimos reales (RQ-SEC-018).

Las de la ejecución de este plan:

## Review Focus

Las cinco entradas que más pueden morder a quien use esto, cada una con su prueba en la tarea dueña del código:

1. **Datos personales en un EXTERNO.** Un nombre de «Persona Ejemplo 1», una foto identificable sin el dato de
   consentimiento, la imagen del comprobante, su número o su emisor, o un texto restringido llegan al PDF que sale a un
   tercero. Se espera que `ReportDisclosure.apply(model, EXTERNO)` no deje nada de eso y cite por cargo, código `GI-` o
   localidad, y que el DOCX escrito desde ese modelo tampoco lo traiga. Pruebas: `ReportDisclosureTest` «EXTERNO no lleva
   nombres, restringidos, emisor, numero, fotos sin consentimiento ni comprobante» y «un dato vacio de consentimiento
   cuenta como identificable sin consentimiento» (Tarea 2) y `DocxWriterTest` «EXTERNO no lleva el nombre de la persona ni
   las fotos sin consentimiento» (Tarea 5).
2. **Servir algo sin marca o el modelo antes de emitir.** Una candidata o `draft_model` bajada por `GET …/draft/content` o
   por la ruta nativa `GET /api/objects/deliverable/records/{id}/files/{field}`, o un archivo de entregable subido por
   `POST /api/objects/…/files/{field}`. Se espera `404` para candidatas, modelo y DOCX fuera de INTERNO, `403
   ACTION_REQUIRED` sin `DOWNLOAD_RESTRICTED` (o sin `EXPORT` en una versión EXTERNO), una fila `DESCARGA` en
   `export_log` por cada descarga servida y `403 FILE_WRITE_NOT_ALLOWED` en las seis rutas de subida. Prueba:
   `DeliverableDownloadsApiTest` (Tarea 12).
3. **Aprobar o emitir algo distinto de lo revisado.** Una sección editada después de congelar el modelo, otro
   `draftModelSha256`, un mapa fallido o un borrador no LISTO. Se espera `409 SECTIONS_CHANGED` (un error por sección),
   `409 MODEL_MISMATCH`, `409 MAP_FAILED` y `409 STATE_MISMATCH` sobre `draft`, sin versiones ni `export_log` creados, y
   `400 CHECKLIST_REQUIRED` sin la lista. Pruebas: `DeliverableWorkflowApiTest` (Tarea 10) y `DeliverableIssueApiTest`
   (Tarea 13).
4. **El borrador escrito por la API genérica o perdido por un PUT.** `draft_*`, `current_version` o `current_revision`
   escritos sin pasar por JOB-05 o la emisión, o un PUT del portal que reenvía los descriptores de los `FILE` derivados tal
   como los leyó y recibe `400 DERIVED_FIELD`. Se espera `400 DERIVED_FIELD` al escribirlos y que reenviar el descriptor
   leído pase (`Values.same` compara archivos por id). Pruebas: `ValuesTest` «un descriptor de archivo es igual a su id y
   distinto de otro archivo» (Tarea 10) y `DeliverableDraftsApiTest` «nadie escribe draft_ ni current_version por la API
   generica, y reenviar los descriptores leidos no es cambiarlos» (Tarea 11).
5. **JOB-05 dos veces sobre el mismo entregable o nunca más.** Dos réplicas generando el mismo borrador, o un pedido que
   queda EN PROCESO para siempre si la réplica se cae. Se espera el candado `sgspe.deliverable:<id>` y que un pedido EN
   COLA o EN PROCESO solo se retome pasado `stale-after`. Pruebas: `DraftQueueTest` (Tarea 11) y `DeliverableDraftsApiTest`
   «un pedido EN PROCESO viejo se retoma y uno reciente no» (Tarea 11).

```kotlin
package sgspe.privacy

import tools.jackson.databind.json.JsonMapper
import tools.jackson.module.kotlin.KotlinModule
import java.security.MessageDigest
import java.util.HexFormat

// la forma canónica del modelo del informe (especificación de F8 §3.2): claves ordenadas, UTF-8, sin espacios, sin
// entradas nulas y los decimales como texto (el modelo no lleva números de coma flotante: uno es un error, no se redondea).
// su SHA-256 es draft_model_sha256, y el archivo draft_model guarda estos mismos bytes, así que el SHA-256 de su descriptor
// es igual. `read` vuelve al modelo: JOB-05 genera desde lo leído, la prueba de que un solo archivo basta para volver a
// generar (RQ-REP-026)
object CanonicalJson {
    private val mapper: JsonMapper = JsonMapper.builder().addModule(KotlinModule.Builder().build()).build()

    fun bytes(model: ReportModel): ByteArray = write(mapper.convertValue(model, Map::class.java)).toByteArray(Charsets.UTF_8)

    fun read(bytes: ByteArray): ReportModel = mapper.readValue(bytes, ReportModel::class.java)

    fun sha256(bytes: ByteArray): String = HexFormat.of().formatHex(MessageDigest.getInstance("SHA-256").digest(bytes))

    // el texto canónico de un árbol de mapas, listas y valores simples
    fun write(value: Any?): String = StringBuilder().also { append(it, value) }.toString()

    private fun append(
        out: StringBuilder,
        value: Any?
    ) {
        when (value) {
            null -> out.append("null")
            is String -> string(out, value)
            is Boolean -> out.append(value)
            is Int, is Long, is Short, is Byte -> out.append(value)
            is Map<*, *> -> {
                out.append('{')
                value.entries
                    .filter { it.value != null }
                    .sortedBy { it.key.toString() }
                    .forEachIndexed { i, (key, item) ->
                        if (i > 0) out.append(',')
                        string(out, key.toString())
                        out.append(':')
                        append(out, item)
                    }
                out.append('}')
            }
            is Iterable<*> -> {
                out.append('[')
                value.forEachIndexed { i, item ->
                    if (i > 0) out.append(',')
                    append(out, item)
                }
                out.append(']')
            }
            else -> throw IllegalArgumentException("El modelo del informe no admite ${value.javaClass.simpleName}: los decimales van como texto")
        }
    }

    private fun string(
        out: StringBuilder,
        text: String
    ) {
        out.append('"')
        for (c in text) {
            when {
                c == '"' -> out.append("\\\"")
                c == '\\' -> out.append("\\\\")
```

```kotlin
package sgspe.privacy

// las menciones de la narrativa (especificación de F8 §2.2.9, ASM-137): tokens Markdown [[person:<id>]],
// [[position:<id>]] o [[stakeholder:<id>]] que apuntan a un registro, nunca el nombre escrito. INTERNO los resuelve al
// nombre; EXTERNO al cargo y la organización, o al código GI-, y sin cargo a «una persona de <localidad>». una mención que
// el modelo no conoce sale como «una persona» en todo nivel: nunca se imprime el id
object Mentions {
    val TOKEN = Regex("""\[\[(person|position|stakeholder):([0-9a-fA-F-]{36})]]""")

    const val UNKNOWN = "una persona"

    // las claves («person:<id>») que cita un texto, en su orden y sin repetir
    fun keys(text: String): List<String> =
        TOKEN
            .findAll(text)
            .map { "${it.groupValues[1]}:${it.groupValues[2].lowercase()}" }
            .distinct()
            .toList()

    fun resolve(
        text: String,
        people: Map<String, MentionTarget>,
        level: Disclosure
    ): String =
        TOKEN.replace(text) { match ->
            val target = people["${match.groupValues[1]}:${match.groupValues[2].lowercase()}"]
            if (target == null) UNKNOWN else cite(target, level)
        }

    fun cite(
        target: MentionTarget,
        level: Disclosure
    ): String =
        when (level) {
            Disclosure.INTERNO -> target.name
            else -> {
                val role = listOfNotNull(target.position, target.organization).joinToString(", ").ifEmpty { null }
                role
                    ?: target.stakeholderCode
                    ?: target.locality?.let { "una persona de $it" }
                    ?: UNKNOWN
            }
        }
}
```

```kotlin
package sgspe.privacy

// el modelo de un nivel (especificación de F8 §3.2, deliverables.md §9): no sabe de tipos, solo de marcas. INTERNO resuelve
// las menciones al nombre y no quita nada. EXTERNO (§2.2.9, §2.2.10, deliverables.md §9.2): quita los párrafos y las tablas
// marcados, vacía las celdas marcadas (nombres de titular o emisor, números de registro o de comprobante), cita a las
// personas por cargo o GI-, deja solo las fotos sin personas identificables o con consentimiento (un vacío no entra) y nunca
// la imagen de un comprobante, y toma la imagen EXTERNO de cada mapa. un bloque de fotos que queda vacío se quita. ningún
// tipo de F8 prepara PUBLICO: pedirlo es un error del programa, no un modelo vacío
object ReportDisclosure {
    fun apply(
        model: ReportModel,
        level: Disclosure
    ): ReportModel {
        require(level != Disclosure.PUBLICO) { "Ningún tipo de entregable de F8 prepara PUBLICO" }
        val external = level == Disclosure.EXTERNO
        val photos = if (external) model.photos.filterValues(::publishable) else model.photos
        val maps =
            model.maps.mapValues { (_, images) ->
                if (external) ReportMapImages(images.external, images.external) else ReportMapImages(images.internal, images.internal)
            }
        val sections =
            model.sections.map { section ->
                section.copy(blocks = section.blocks.mapNotNull { block(it, model.people, level, photos.keys) })
            }
        return model.copy(
            meta = model.meta.copy(level = level.name),
            sections = sections,
            people = emptyMap(),
            photos = photos,
            maps = maps
        )
    }

    // una foto entra en EXTERNO si no muestra personas identificables o tiene consentimiento; un comprobante, nunca (ASM-037)
    fun publishable(photo: PhotoRef): Boolean = photo.kind != PhotoRef.RECEIPT && (photo.identifiable == false || photo.consent == true)

    private fun block(
        block: Block,
        people: Map<String, MentionTarget>,
        level: Disclosure,
        photos: Set<String>
    ): Block? {
        val external = level == Disclosure.EXTERNO
        return when (block) {
            is Block.Paragraph ->
                if (external && block.mark != null) {
                    null
                } else {
                    block.copy(
                        markdown = Mentions.resolve(block.markdown, people, level),
                        footnotes = block.footnotes.map { Mentions.resolve(it, people, level) }
                    )
                }
            is Block.Table ->
                if (external && block.mark != null) {
                    null
                } else {
                    block.copy(
                        rows =
                            block.rows.map { row ->
                                row.map { cell ->
                                    if (external && cell.mark != null) cell.copy(text = "") else cell.copy(text = Mentions.resolve(cell.text, people, level))
                                }
                            }
                    )
                }
            is Block.Photos -> block.copy(evidence = block.evidence.filter { it in photos }).takeIf { it.evidence.isNotEmpty() }
            is Block.Heading -> block.copy(text = Mentions.resolve(block.text, people, level))
            is Block.MapFigure, is Block.SectionBreak -> block
        }
    }
}
```

```kotlin
package sgspe.privacy

// el aviso determinista de datos personales (especificación de F8 §2.2.9, ASM-137): en la narrativa y en los textos de
// registro de cada sección busca nombres de `person` del proyecto, números de 8 dígitos (un DNI), teléfonos y correos, y
// avisa POSSIBLE_PERSONAL_DATA con la clave de la sección, una vez por sección. es una ayuda para la lista de verificación
// de EXTERNO, no una garantía: un nombre que no está registrado no se ve. las menciones [[…:<id>]] no cuentan: se quitan
// antes de buscar. el aviso nunca lleva lo encontrado
object PersonalDataScan {
    const val CODE = "POSSIBLE_PERSONAL_DATA"

    private val EIGHT_DIGITS = Regex("""(?<![0-9A-Za-z])\d{8}(?![0-9A-Za-z])""")
    private val PHONE = Regex("""(?<![0-9])(\+?51[ -]?)?9\d{2}[ -]?\d{3}[ -]?\d{3}(?![0-9])""")
    private val EMAIL = Regex("""[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}""")

    // `texts`: los textos de cada sección por su clave; `names`: los nombres completos de las personas del proyecto (de dos
    // palabras o más: un nombre de pila suelto daría avisos en cualquier texto)
    fun scan(
        texts: Map<String, List<String>>,
        names: Collection<String>
    ): List<ReportWarning> {
        val wanted = names.map { normalize(it) }.filter { it.split(' ').size >= 2 }.distinct()
        return texts.mapNotNull { (section, values) ->
            val found =
                values.any { raw ->
                    val text = Mentions.TOKEN.replace(raw, " ")
                    val plain = normalize(text)
                    EIGHT_DIGITS.containsMatchIn(text) ||
                        PHONE.containsMatchIn(text) ||
                        EMAIL.containsMatchIn(text) ||
                        wanted.any { " $it " in " $plain " }
                }
            if (found) ReportWarning(CODE, section) else null
        }
    }

    // minúsculas, sin tildes y con un solo espacio entre palabras
    private fun normalize(text: String): String =
        java.text.Normalizer
            .normalize(text.lowercase(), java.text.Normalizer.Form.NFD)
            .replace(Regex("\\p{M}+"), "")
            .replace(Regex("[^a-zñ0-9]+"), " ")
            .trim()
}
```

```kotlin
        if (previous == null || reset || !previous.all { it in 'A'..'Z' }) return scheme.draftStart
        return letters(number(previous) + 1)
    }

    fun nextIssue(
        current: String?,
        scheme: DeliverableProperties.Scheme
    ): String = current?.toIntOrNull()?.let { (it + 1).toString() } ?: scheme.issueStart.toString()

    // A = 1, Z = 26, AA = 27 (base 26 sin cero)
    private fun number(label: String): Int = label.fold(0) { n, c -> n * 26 + (c - 'A' + 1) }

    private fun letters(n: Int): String {
        var rest = n
        val out = StringBuilder()
        while (rest > 0) {
            val digit = (rest - 1) % 26
            out.insert(0, 'A' + digit)
            rest = (rest - 1) / 26
        }
        return out.toString()
    }
```

```kotlin
import org.apache.poi.openxml4j.opc.OPCPackage
import org.apache.poi.xwpf.usermodel.BreakType
import org.apache.poi.xwpf.usermodel.ParagraphAlignment
import org.apache.poi.xwpf.usermodel.XWPFDocument

import org.apache.poi.xwpf.usermodel.XWPFStyle
import org.openxmlformats.schemas.wordprocessingml.x2006.main.CTFonts
import org.openxmlformats.schemas.wordprocessingml.x2006.main.CTStyle
import org.openxmlformats.schemas.wordprocessingml.x2006.main.STStyleType
import java.io.ByteArrayInputStream
import java.io.ByteArrayOutputStream
import java.math.BigInteger

// la plantilla base de SGSPE (especificación de F8 §3.3, ASM-135): rige cuando el entregable no tiene template_key. la arma
// este código con POI, con solo Liberation Sans y los estilos de TemplateStyles, y la portada con los marcadores fijos;
// TemplateValidatorTest la valida como a una subida. es código y no un .dotx versionado (decisión 6 del plan 8.2b): se revisa
// en un diff y no envejece fuera de la lista de estilos. sale como .dotx (el tipo de contenido de una plantilla de Word)
object BaseTemplate {
    const val SHA_LABEL = "sgspe-base"
    private const val FONT = "Liberation Sans"

    val bytes: ByteArray by lazy { build() }

    private fun build(): ByteArray {
        val docx =
            XWPFDocument().use { doc ->
                val styles = doc.createStyles()
                styles.setDefaultFonts(fonts())
                style(doc, "Normal", TemplateStyles.NORMAL, 22, bold = false, outline = null)
                style(doc, "Title", TemplateStyles.TITLE, 40, bold = true, outline = null)
                style(doc, "Heading1", TemplateStyles.HEADING_1, 28, bold = true, outline = 0)
                style(doc, "Heading2", TemplateStyles.HEADING_2, 24, bold = true, outline = 1)
                style(doc, "Heading3", TemplateStyles.HEADING_3, 22, bold = true, outline = 2)
                style(doc, "Caption", TemplateStyles.CAPTION, 20, bold = true, outline = null)
                style(doc, "ListParagraph", TemplateStyles.LIST, 22, bold = false, outline = null)
                cover(doc, "Title", "{{titulo}}")
                cover(doc, null, "{{proyecto}}")
                cover(doc, null, "{{mapa_portada}}")
                cover(doc, null, "Preparado para: {{preparado_para}}")
                cover(doc, null, "Suscrito por: {{suscrito_por}}")
                cover(doc, null, "{{direccion_autora}}")
                cover(doc, null, "{{fecha}}")
                doc.createParagraph().createRun().addBreak(BreakType.PAGE)
                ByteArrayOutputStream().also { doc.write(it) }.toByteArray()
            }
        // del tipo de documento al de plantilla (.dotx)
        return OPCPackage.open(ByteArrayInputStream(docx)).use { pkg ->
            pkg.replaceContentType(XWPFRelation.DOCUMENT.contentType, XWPFRelation.TEMPLATE.contentType)
            ByteArrayOutputStream().also { pkg.save(it) }.toByteArray()
        }
    }

    private fun fonts(): CTFonts =
        CTFonts.Factory.newInstance().apply {
            ascii = FONT
            hAnsi = FONT
            cs = FONT
            eastAsia = FONT
        }

    private fun style(
        doc: XWPFDocument,
        id: String,
        name: String,
        halfPoints: Int,
        bold: Boolean,
        outline: Int?
    ) {
        val ct = CTStyle.Factory.newInstance()
        ct.styleId = id
        ct.type = STStyleType.PARAGRAPH
        ct.addNewName().setVal(name)
        if (id != "Normal") ct.addNewBasedOn().setVal("Normal")
        ct.addNewQFormat()
        outline?.let { ct.addNewPPr().addNewOutlineLvl().setVal(BigInteger.valueOf(it.toLong())) }
        val rpr = ct.addNewRPr()
        rpr.addNewRFonts().set(fonts())
        rpr.addNewSz().setVal(BigInteger.valueOf(halfPoints.toLong()))
        if (bold) rpr.addNewB()
        doc.styles.addStyle(XWPFStyle(ct))
    }

    private fun cover(
        doc: XWPFDocument,
        style: String?,
        text: String
    ) {
        val p = doc.createParagraph()
        style?.let { p.style = it }
        p.alignment = ParagraphAlignment.CENTER
        p.createRun().setText(text)
    }
}
```

```kotlin
// y JPEG de calidad `quality` (sgspe.deliverable.photos), sobre fondo blanco si traía transparencia. sin pantalla (Java 2D
// headless). null si los bytes no son una imagen que ImageIO lea
object PhotoResize {
    data class Resized(
        val jpeg: ByteArray,
        val width: Int,
        val height: Int
    )

    fun jpeg(
        bytes: ByteArray,
        maxSide: Int,
        quality: Int
    ): Resized? {
        val source = ImageIO.read(ByteArrayInputStream(bytes)) ?: return null
        val scale = minOf(1.0, maxSide.toDouble() / maxOf(source.width, source.height))
        val width = maxOf(1, (source.width * scale).toInt())
        val height = maxOf(1, (source.height * scale).toInt())
        val target = BufferedImage(width, height, BufferedImage.TYPE_INT_RGB)
        val g = target.createGraphics()
        try {
            g.setRenderingHint(RenderingHints.KEY_INTERPOLATION, RenderingHints.VALUE_INTERPOLATION_BICUBIC)
            g.color = Color.WHITE
            g.fillRect(0, 0, width, height)
            g.drawImage(source, 0, 0, width, height, null)
        } finally {
            g.dispose()
        }
        val writer = ImageIO.getImageWritersByFormatName("jpeg").next()
        val out = ByteArrayOutputStream()
        try {
            ImageIO.createImageOutputStream(out).use { stream ->
                writer.output = stream
                val param =
                    writer.defaultWriteParam.apply {
                        compressionMode = ImageWriteParam.MODE_EXPLICIT
                        compressionQuality = quality / 100f
                    }
                writer.write(null, IIOImage(target, null, null), param)
            }
        } finally {
            writer.dispose()
        }
        return Resized(out.toByteArray(), width, height)
    }
}
```

```kotlin
        doc: XWPFDocument,

        node: Node,

            is Paragraph ->
                paragraph(doc, if (prefix == null) styles.normal else styles.list).also { p ->
                    prefix?.let { p.createRun().setText(it) }
                    inline(p, node, false, false)
                }
            is BulletList, is OrderedList -> {

                var item = node.firstChild

                        var first = true

                            last = markdownBlock(doc, styles, child, if (first) marker else "") ?: last
                            first = false
                            child = child.next
                        }
                    }
                    item = item.next
                }
                last
            }
            is BlockQuote -> {
                var last: XWPFParagraph? = null
                var child = node.firstChild
                while (child != null) {
                    last = markdownBlock(doc, styles, child, prefix) ?: last
                    child = child.next
                }
                last

            is IndentedCodeBlock -> literal(doc, styles, node.literal)

    // la grilla de una tabla: cada celda en la primera posición libre de su fila; colSpan con gridSpan, rowSpan con vMerge
    private fun grid(
        doc: XWPFDocument,
        styles: StyleIds,
        header: List<String>,
        rows: List<List<Cell>>
    ): XWPFTable {
        val columns = maxOf(1, header.size)
        val table = doc.createTable(rows.size + 1, columns)
        styles.table?.let { table.styleID = it }
        header.forEachIndexed { c, text -> cellText(table.getRow(0).getCell(c), text, bold = true) }
        table.getRow(0).isRepeatHeader = true
        val occupied = Array(rows.size) { BooleanArray(columns) }
        val removed = Array(rows.size) { mutableSetOf<Int>() }
        rows.forEachIndexed { r, row ->
            var c = 0
            for (cell in row) {
                while (c < columns && occupied[r][c]) c++
                if (c >= columns) break
                val colSpan = cell.colSpan.coerceIn(1, columns - c)
                val rowSpan = cell.rowSpan.coerceIn(1, rows.size - r)
                for (dr in 0 until rowSpan) {
                    for (dc in 0 until colSpan) {
                        occupied[r + dr][c + dc] = true
                        if (dc > 0) removed[r + dr] += c + dc
                    }
                    val target = table.getRow(r + dr + 1).getCell(c)
                    val pr = target.ctTc.tcPr ?: target.ctTc.addNewTcPr()
                    if (colSpan > 1) pr.addNewGridSpan().setVal(BigInteger.valueOf(colSpan.toLong()))
                    if (rowSpan > 1) pr.addNewVMerge().setVal(if (dr == 0) STMerge.RESTART else STMerge.CONTINUE)
                }
                cellText(table.getRow(r + 1).getCell(c), cell.text, bold = false)
                c += colSpan
            }
        }
        removed.forEachIndexed { r, columnsToRemove -> columnsToRemove.sortedDescending().forEach { table.getRow(r + 1).removeCell(it) } }
        return table
    }
```

```kotlin
package sgspe.deliverable

import org.apache.poi.openxml4j.opc.OPCPackage
import org.apache.poi.xwpf.usermodel.XWPFDocument
import org.apache.poi.xwpf.usermodel.XWPFTable
import java.io.ByteArrayInputStream
import java.util.zip.ZipException
import java.util.zip.ZipInputStream

// una violación o un aviso de una plantilla: el código y un detalle sin datos del archivo más allá de nombres de estilos,
// fuentes y marcadores
data class TemplateFinding(
    val code: String,
    val detail: String
)

data class TemplateReport(
    val violations: List<TemplateFinding>,
    val warnings: List<TemplateFinding>
) {
    val valid: Boolean get() = violations.isEmpty()
}

// la validación de una plantilla Word (especificación de F8 §2.2.12 y §3.3, ASM-135, RQ-SEC-019): primero el ZIP con límites
// de entradas y de bytes descomprimidos, sin abrirlo con POI (una bomba no llega a POI); después rechaza las macros
// (vbaProject.bin, tipos .dotm y .docm), los objetos OLE, ActiveX, los controles de contenido, las relaciones
// TargetMode="External", los marcadores desconocidos, los estilos requeridos que faltan (TemplateStyles, por nombre) y las
// fuentes fuera de la lista en un estilo, en el texto o en el tema que los estilos citan; una fuente que solo figura en la
// tabla de fuentes es un aviso. trabajo bloqueante: quien llama lo corre en Dispatchers.IO
class TemplateValidator(
    private val limits: DeliverableProperties.Templates
) {
    fun validate(
        bytes: ByteArray,
        fileName: String
    ): TemplateReport {
        val violations = mutableListOf<TemplateFinding>()
        val warnings = mutableListOf<TemplateFinding>()
        val name = fileName.lowercase()
        if (name.endsWith(".dotm") || name.endsWith(".docm")) violations += TemplateFinding(MACROS, "el tipo de archivo admite macros")
        if (!(name.endsWith(".dotx") || name.endsWith(".docx") || name.endsWith(".dotm") || name.endsWith(".docm"))) {
            violations += TemplateFinding(NOT_WORD, "solo plantillas .dotx o .docx")
        }
        if (bytes.size > limits.maxBytes) return TemplateReport(violations + TemplateFinding(TOO_LARGE, "pasa de ${limits.maxBytes} bytes"), warnings)
        val entries = entries(bytes) ?: return TemplateReport(violations + TemplateFinding(NOT_WORD, "no es un documento OOXML"), warnings)
        if (entries.overflow != null) return TemplateReport(violations + TemplateFinding(TOO_LARGE, entries.overflow), warnings)
        val parts = entries.parts
        if (parts.keys.none { it == "word/document.xml" }) return TemplateReport(violations + TemplateFinding(NOT_WORD, "falta word/document.xml"), warnings)
        if (parts.keys.any { it.substringAfterLast('/').equals("vbaProject.bin", ignoreCase = true) } ||
            "macroEnabled" in parts["[Content_Types].xml"].orEmpty()
        ) {
            violations += TemplateFinding(MACROS, "la plantilla trae macros")
        }
        val content = parts.filterKeys { it.startsWith("word/") && it.endsWith(".xml") }
        if (parts.keys.any { it.startsWith("word/embeddings/") } || content.values.any { "<o:OLEObject" in it || "<w:object" in it }) {
            violations += TemplateFinding(OLE_OBJECT, "la plantilla trae objetos incrustados")
        }
        if (parts.keys.any { it.startsWith("word/activeX/") } || content.values.any { "<w:control" in it }) {
            violations += TemplateFinding(ACTIVEX, "la plantilla trae controles ActiveX")
        }
        if (content.values.any { "<w:sdt>" in it || "<w:sdt " in it }) {
            violations +=
                TemplateFinding(CONTENT_CONTROL, "la plantilla trae controles de contenido")
        }
        if (parts.filterKeys { it.endsWith(".rels") }.values.any { EXTERNAL.containsMatchIn(it) }) {
            violations += TemplateFinding(EXTERNAL_RELATIONSHIP, "la plantilla cita archivos o direcciones externas")
        }
        if (violations.isNotEmpty()) return TemplateReport(violations.distinct(), warnings)
        try {
            XWPFDocument(OPCPackage.open(ByteArrayInputStream(bytes))).use { doc ->
                placeholders(doc).filter { it !in TemplateStyles.PLACEHOLDERS }.distinct().forEach {
                    violations += TemplateFinding(UNKNOWN_PLACEHOLDER, "{{$it}}")
                }
                TemplateStyles.REQUIRED.filter { doc.styles?.getStyleWithName(it) == null }.forEach {
                    violations += TemplateFinding(MISSING_STYLE, it)
                }
            }
        } catch (e: Exception) {
            return TemplateReport(violations + TemplateFinding(NOT_WORD, "POI no puede abrir el documento"), warnings)
        }
        val styled = listOfNotNull(parts["word/styles.xml"], parts["word/document.xml"]) + parts.filterKeys { HEADER_FOOTER.matches(it) }.values
        val used =
            styled
                .flatMap { xml -> RFONTS.findAll(xml).flatMap { tag -> FONT_ATTRIBUTE.findAll(tag.groupValues[1]).map { it.groupValues[1] } } }
                .toSet()
        val themed = THEME_ATTRIBUTE.containsMatchIn(parts["word/styles.xml"].orEmpty() + parts["word/document.xml"].orEmpty())
        val theme =
            if (themed) {
                THEME_FONT
                    .findAll(parts["word/theme/theme1.xml"].orEmpty())
                    .map {
                        it.groupValues[1]
                    }.filter { it.isNotEmpty() }
                    .toSet()
            } else {
                emptySet()
            }
        (used + theme).filter { it !in TemplateStyles.FONTS }.sorted().forEach { violations += TemplateFinding(FONT_NOT_ALLOWED, it) }
        val table = TABLE_FONT.findAll(parts["word/fontTable.xml"].orEmpty()).map { it.groupValues[1] }.toSet()
        (table - used - theme).filter { it !in TemplateStyles.FONTS }.sorted().forEach { warnings += TemplateFinding(FONT_IN_TABLE, it) }
        return TemplateReport(violations, warnings)
    }

    // los marcadores del cuerpo (también en tablas), los encabezados y los pies, sobre el texto del párrafo (que ya junta las
    // corridas partidas)
    private fun placeholders(doc: XWPFDocument): List<String> {
        fun tables(list: List<XWPFTable>) = list.flatMap { t -> t.rows.flatMap { r -> r.tableCells.flatMap { it.paragraphs } } }
        val paragraphs =
            doc.paragraphs + tables(doc.tables) + doc.headerList.flatMap { it.paragraphs + tables(it.tables) } +
                doc.footerList.flatMap { it.paragraphs + tables(it.tables) }
        return paragraphs.flatMap { p ->
            TemplateStyles.PLACEHOLDER
                .findAll(p.text)
                .map { it.groupValues[1] }
                .toList()
        }
    }

    private class Entries(
        val parts: Map<String, String>,
        val overflow: String?
    )

    // las partes XML y .rels como texto y los nombres de las demás, con los topes de entradas y de bytes descomprimidos
    private fun entries(bytes: ByteArray): Entries? {
        val parts = linkedMapOf<String, String>()
        var count = 0
        var inflated = 0L
        try {
            ZipInputStream(ByteArrayInputStream(bytes)).use { zip ->
                while (true) {
                    val entry = zip.nextEntry ?: break
                    if (++count > limits.maxEntries) return Entries(parts, "más de ${limits.maxEntries} entradas")
                    val buffer = java.io.ByteArrayOutputStream()
                    val chunk = ByteArray(BUFFER)
                    while (true) {
                        val n = zip.read(chunk)
                        if (n < 0) break
                        inflated += n
                        if (inflated > limits.maxInflatedBytes) return Entries(parts, "más de ${limits.maxInflatedBytes} bytes descomprimidos")
                        if (entry.name.endsWith(".xml") || entry.name.endsWith(".rels")) buffer.write(chunk, 0, n)
                    }
                    parts[entry.name] = buffer.toString(Charsets.UTF_8)
                }
            }
        } catch (_: ZipException) {
            return null
        }
        return if (parts.isEmpty()) null else Entries(parts, null)
    }

    companion object {
        const val MACROS = "MACROS"
        const val OLE_OBJECT = "OLE_OBJECT"
        const val ACTIVEX = "ACTIVEX"
        const val CONTENT_CONTROL = "CONTENT_CONTROL"
        const val EXTERNAL_RELATIONSHIP = "EXTERNAL_RELATIONSHIP"
        const val UNKNOWN_PLACEHOLDER = "UNKNOWN_PLACEHOLDER"
        const val MISSING_STYLE = "MISSING_STYLE"
        const val FONT_NOT_ALLOWED = "FONT_NOT_ALLOWED"
        const val FONT_IN_TABLE = "FONT_IN_TABLE"
        const val NOT_WORD = "NOT_WORD"
        const val TOO_LARGE = "TOO_LARGE"
        private const val BUFFER = 8192

        private val EXTERNAL = Regex("""TargetMode\s*=\s*"External"""")
        private val RFONTS = Regex("""<w:rFonts\b([^>]*)>""")
        private val FONT_ATTRIBUTE = Regex("""\bw:(?:ascii|hAnsi|cs|eastAsia)="([^"]+)"""")
        private val THEME_ATTRIBUTE = Regex("""w:(?:ascii|hAnsi|cs|eastAsia)Theme=""")
        private val THEME_FONT = Regex("""<a:latin typeface="([^"]*)"""")
        private val TABLE_FONT = Regex("""<w:font w:name="([^"]+)"""")
        private val HEADER_FOOTER = Regex("""word/(header|footer)\d*\.xml""")
    }
}
```
