# SGSPE · Fase 4, plan 4.1 (modelo y aprovisionamiento): plan de implementación

> **Para agentes:** SUB-SKILL OBLIGATORIA: usar superpowers:subagent-driven-development (recomendada) o
> superpowers:executing-plans para ejecutar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`) para el
> seguimiento. Cada tarea de código sigue superpowers:test-driven-development: prueba que falla, implementación mínima,
> prueba en verde, commit.

**Goal:** Dejar en `~/IdeaProjects/sgspe` el modelo de F4 («Quejas, consultas y solicitudes, riesgos y alertas») como
código y aprovisionado de punta a punta: los 12 objetos de BC-07, BC-08 y BC-09, los 8 parámetros de `project` «Desde
F4», `engagement_question.referred_at`, `early_warning.generator_key`, las relaciones de F4 en `commitment`, `evidence`
y `task`, los 16 ENUM nuevos y la acción `READ_CONFIDENTIAL` en `model/model.json`; WF-E1, WF-E2, WF-E3, WF-F, WF-J y
WF-M, con `GRIEVANCE_MANAGER` y `SOCIAL_RISK_MANAGER` en WF-N; AUT-02, AUT-09 y AUT-11; las concesiones de §7.6 y la
persona restringida de las QCS en `model/roles.json`; y la base de pruebas que heredan los planes 4.2a y 4.2b.

**Architecture:** El modelo sigue siendo datos en `model/` aplicados por REST con Python de solo biblioteca estándar
(ADR-0007). `design_docs.py` aprende a leer las subsecciones de WF-E1, WF-E2 y WF-E3; `apply.py` rechaza la condición de
una automatización con un valor que su campo no puede tener (AUT-11 es la primera que compara un ENUM); dos generadores
de un solo uso (fuera del repositorio) escriben `model.json` y `roles.json` desde las fichas y la matriz de
`security.md`, conservando lo de F2 y F3 tal cual. Del lado de Kotlin, este plan solo toca lo que el modelo nuevo
rompería sin tocarlo (el grupo de orígenes de `task` en `ExactlyOneGuard`, el umbral de las reglas en
`AmountFieldsGuard.NOT_MONEY`) y deja `sgspe.F4ApiTest`, que arma QCS, riesgos, incidentes y alertas que ya cumplen las
guardas de 4.2.

**Tech Stack:** Kotlin 2.4.20, Spring Boot 4.1.1 (WebFlux), JDK 25, Gradle 9.8.0, `wasichai-bom` 0.6.0 (sin starters
nuevos en F4); JUnit 5 con `wasichai-test`; PostgreSQL 18 con PostGIS 3.6; Python 3.11 o superior (solo biblioteca
estándar).

**Spec:** `docs/superpowers/specs/2026-10-09-fase-4-design.md` (vinculante): §1 (alcance), §2 (decisiones 1 a 8 y
elecciones 1 a 10), §3.1 (piezas comunes: `ExactlyOneGuard`, parámetros, transiciones de comando, `generator_key`), §3.2
y §3.3 (objetos de QCS, `READ_CONFIDENTIAL`, `person` restringido), §3.5 (automatizaciones), §3.6, §3.7, §3.9 (ningún
tipo de documento en F4), §4 (los seis tipos de regla) y §7 (fila 4.1). Los documentos como quedan tras el plan 4.0
(`docs/superpowers/plans/2026-10-09-fase-4-0-documentos.md`): `docs/database-model.md` §6 y §12 a §17,
`docs/requirements-analysis.md` §10, `docs/workflows.md` (WF-E a WF-N, «Automatizaciones», tipos de documento),
`docs/domain-model.md` §7.3 y `docs/security.md` §5.3, §7.1, §7.6 y §7.9.

## Global Constraints

- **Repositorio.** Todo el trabajo en `~/IdeaProjects/sgspe`, en la rama `feat/fase-4-1-modelo` creada desde `main` con
  el plan 4.0 integrado. Los planes 4.2a y 4.2b parten de esta rama ya integrada.
- **Versiones.** Las de F3, sin cambios: wasichai `0.6.0` exacto, Kotlin `2.4.20`, Spring Boot `4.1.1`, JDK `25`, Gradle
  `9.8.0`. F4 no trae starters nuevos.
- **Idioma.** Español (es-PE) en documentos, comentarios y mensajes; nombres técnicos en inglés (ADR-0009); valores ENUM
  en español MAYÚSCULAS sin tildes (CON-050, ASM-025), salvo la Ñ que ya traen los catálogos («CONTEO DE SEÑALES»).
- **Python.** Solo biblioteca estándar, 3.11 o superior. `model/` está fuera de prettier: `model.json`, `roles.json` y
  los JSON de `workflows/` y `automations/` tienen el formato a mano de este plan.
- **Gradle.** Siempre `GITHUB_ACTOR=$(gh api user -q .login) GITHUB_TOKEN=$(gh auth token) ./gradlew …` desde
  `~/IdeaProjects/sgspe`; `./gradlew ktlintFormat` antes de `build`. El token nunca va a un archivo ni a la salida. Con
  poca memoria, agregar `-Pkotlin.daemon.jvmargs=-Xmx3g`.
- **Integración.** La corre el coordinador, no el implementador ni un subagente: el implementador compila
  (`compileTestKotlin` o `build`), corre las pruebas de Python y entrega la tarea marcada «integración pendiente» con
  las clases que nombra su último paso. Con el túnel abierto:
  `WASICHAI_TEST_DB_HOST=localhost WASICHAI_TEST_DB_PORT=5435 WASICHAI_TEST_DB_NAME=sgspe_sdd_test WASICHAI_TEST_DB_USERNAME=sgspe WASICHAI_TEST_DB_PASSWORD=sgspe GITHUB_ACTOR=$(gh api user -q .login) GITHUB_TOKEN=$(gh auth token) ./gradlew integrationTest --rerun --tests '<clase>'`.
  La primera clase de la JVM aprovisiona el modelo de F4 (por el túnel, más que los 5 a 8 minutos de F2, con 72
  objetos); conviene correr juntas las clases de una tarea (riesgo 5 de la especificación). En la CI corre con
  Testcontainers.
- **Base compartida.** `sgspe_sdd_test` no la usan dos suites a la vez (la suite la vacía una vez por JVM).
- **Modelo.** Ningún campo con `editable`; un derivado lleva `"derived": true`. Ningún tipo de documento sobre un objeto
  con campos restringidos (UPS-23, decisión 3): ni «Cargo de queja» ni «Carta de respuesta» ni AUT-06, AUT-07 o AUT-08.
- **Roles.** Nunca un literal de rol en `src/main/kotlin` (`ArchitectureTest`). Los literales de rol de este plan están
  en `model/` y en `src/test/kotlin`. Un rol entra en una transición desde su fase: `SOCIAL_INVESTMENT_MANAGER` no está
  en `accept` ni en `close_accepted` de WF-E3 hasta F5.
- **Datos.** Ningún nombre real de persona: «Persona Ejemplo N», «Asociación Ejemplo», «Radio Ejemplo», correos
  `@sgspe.test`.
- **Commits.** Conventional Commits con asunto en español; cuerpo de 100 columnas como máximo (contadas en caracteres);
  al final, tras una línea en blanco, `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>` y
  `Claude-Session: https://claude.ai/code/session_017MAgYcNauGp6cC3ekX1h7U`. `git add` solo con rutas explícitas. Push y
  PR en la Tarea 7.
- **Generadores.** `gen_model_f4.py` y `gen_roles_f4.py` se guardan en el scratchpad de quien ejecuta (`$SCRATCH`, fuera
  del repositorio), se corren una vez y no se versionan: desde aquí `model.json` y `roles.json` se editan a mano y
  `test_model.py` y `test_apply_roles.py` los mantienen iguales a los documentos.

## Review Focus

1. **Subir de fase un tenant que ya tiene F2 o F3.** El tenant de desarrollo sigue en F2 (roadmap, «Estado» de F3) y uno
   de producción estaría en F3: `apply.py` agrega solo lo de F4, no toca un objeto anterior y una segunda corrida no
   escribe. Pruebas: `test_a_tenant_of_f3_moves_to_f4_adding_only_what_f4_brings` y
   `test_a_tenant_of_f2_moves_to_f4_in_one_run_and_a_second_run_changes_nothing` (Tarea 3), y la subida real del tenant
   de desarrollo en la Tarea 7.
2. **Una condición de automatización con un valor que su campo no puede tener.** wasichai compara el texto tal cual
   (`AutomationRules.same`): un `risk_level EQUALS Crítico` haría que AUT-11 se salte para siempre sin error. Pruebas:
   `test_a_condition_value_the_field_can_never_hold_is_refused` y `test_a_condition_value_the_field_holds_is_valid`
   (Tarea 2) y «AUT-11 crea una sola tarea cuando el riesgo pasa a CRITICO» (Tarea 5), que además ejercita `CHANGED` y
   una escritura de la plataforma (riesgo 2 de la especificación).
3. **Una tarea automática con un origen de F4.** AUT-02, AUT-09 y AUT-11 crean tareas con una queja, una alerta o un
   riesgo de origen; con el grupo de F3, `ExactlyOneGuard` las rechazaría y la automatización terminaría FAILED.
   Pruebas: «el origen de una tarea es uno de los de su ficha que ya están en el modelo» (`GuardTablesCatalogTest`,
   Tarea 3) y las tres de `AutomationsApiTest` (Tarea 5).
4. **La persona que plantea una QCS.** `person` de las tres QCS es un campo restringido: un rol que no está en §7.9 no
   la recibe ni por id ni en la lista, y quien la registra la escribe. Pruebas: «cada campo restringido de roles json
   falta en el registro y en la lista de quien no lo lee» pasa de 8 a 11 entradas cubiertas (`FieldPermissionsApiTest`,
   Tarea 4), `test_quien_conserva_una_relacion_restringida_a_person_lee_sus_nombres` (ya existe) y
   `test_las_qcs_restringen_su_persona_y_no_tienen_tipos_de_documento` (Tarea 3).
5. **Un rol que aplica una transición que no puede completar.** `RequestClosureListener` aplica `close_accepted` como
   quien cierra el compromiso: si un rol de `close` de WF-D no estuviera en `close_accepted` o no actualizara la
   solicitud, el cierre del compromiso se revertiría; y un rol de un comando sin CREATE sobre lo que el comando escribe
   recibiría 403 a mitad de la transacción. Pruebas: `test_quien_cierra_un_compromiso_cierra_su_solicitud`,
   `test_los_roles_de_cada_comando_de_f4_crean_lo_que_el_comando_escribe` y
   `test_un_rol_de_una_fase_posterior_no_esta_en_ningun_workflow` (Tarea 3).

```python
def workflow_transitions(letter, obj=None):
    """The transitions of the WF-<letter> section of workflows.md: [{name, label, from, to, roles}] in table order.

    Fails (ValueError) when the section, its table or a cell does not have the expected shape, so a changed document
    cannot make a test compare against less than the document says. The cell "Los mismos de `x`" takes the roles of x;
    the cell "Roles <adjective>" takes the roles of the section's bullet "- **Roles <adjective>:**". A section with one
    table per object (WF-K) needs `obj`: the table that follows its "**Objeto:** `obj`" line. A letter with a number
    (WF-E1, WF-E2, WF-E3) is a "### WF-E1 ·" subsection of its letter's section, and ends at the next heading of its
    level or above; "E" alone is the whole section, with its three tables, so it needs `obj`.
    """
    lines = read("workflows.md").splitlines()
    heading = re.compile(rf"^(##|###) WF-{re.escape(letter)} ·")
    starts = [i for i, line in enumerate(lines) if heading.match(line)]
    if len(starts) != 1:
        raise ValueError(f"workflows.md has {len(starts)} sections that start with 'WF-{letter} ·', expected 1")
    # a "## " section ends at the next "## "; a "### " subsection also at the next "### "
    level = heading.match(lines[starts[0]]).group(1)
    stops = ("## ",) if level == "##" else ("## ", "### ")
    end = next((i for i in range(starts[0] + 1, len(lines)) if lines[i].startswith(stops)), len(lines))
```

```python
def field_label(obj, field):
    if (obj, field["name"]) in FIELD_LABEL:
        return FIELD_LABEL[(obj, field["name"])]
    text = field["description"].replace("(derivado)", "").replace("(restringido)", "").replace('"', "").strip()
    text = d.strip_parens(text).replace("`", "")
    text = re.split(r"; |: |\. |, |\.$", text)[0]
    return text.strip().rstrip(".")


def relationship_label(cards, plural, rel):
    if rel["name"] in RELATIONSHIP_LABEL:
        return RELATIONSHIP_LABEL[rel["name"]]
    # the links of an evidence name what it proves: the plural of the target
    if rel["name"].startswith("evidence_") and rel["type"] == "MANY_TO_MANY":
        return plural[rel["target"]]
    # a note that only says when the relationship arrives ("desde F4") names nothing: the target's label
    note = re.sub(r"(^|;\s*)[Dd]esde F\d\s*$", "", rel["note"]).strip()
    if note in ("", "—"):
        return cards[rel["target"]].label
    return d.strip_parens(note.split(";")[0]).strip()


def new_field(name, f):
    out = {"name": f["name"], "label": field_label(name, f), "type": f["type"]}
    if f["type"] == "ENUM":
        out["enum"] = f["enum"]
    if f["type"] == "GEOMETRY":
        out.update({"geometryType": f["geometryType"], "srid": 4326, "dimension": 2})
    if f["name"] in CARDS[name].content_types:
        out["contentTypes"] = CARDS[name].content_types[f["name"]]
    if f["required"]:
        out["required"] = True
    if f["unique"]:
        out["unique"] = True
    if f["name"] in CARDS[name].indexed:
        out["indexed"] = True
    if f["derived"]:
        out["derived"] = True
    if f["default"] is not None:
        out["defaultValue"] = f["default"]
    out["description"] = f["description"].replace("`", "")
    return out


def build():
    existing = json.load(open(os.path.join("model", "model.json"), encoding="utf-8"))
    old_objects = {o["name"]: o for o in existing["objects"]}
    old_rels = {r["name"]: r for r in existing["relationships"]}
    catalog = d.matrix()
    plural = {o["name"]: o["pluralLabel"] for o in existing["objects"]} | PLURAL
    objects, relationships, used = [], [], set()
    for name, card in CARDS.items():
        if card.phase > PHASE or name not in catalog:
            continue
        old = old_objects.get(name)
        old_fields = {f["name"]: f for f in old["fields"]} if old else {}
        fields = [old_fields.get(f["name"]) or new_field(name, f) for f in card.fields if d.field_phase(card, f) <= PHASE]
        used |= {f["enum"] for f in fields if f["type"] == "ENUM"}
        if old:
            obj = {k: v for k, v in old.items() if k != "fields"}
        else:
            obj = {"name": name, "label": card.label, "pluralLabel": PLURAL[name],
                   "description": card.description.replace("`", "")}
            obj.update({flag: True for flag, on in card.flags.items() if on})
            if card.unique_constraints:
                obj["uniqueConstraints"] = card.unique_constraints
            if card.indexes:
                obj["indexes"] = card.indexes
            if card.actions:
                obj["actions"] = [{"name": a, "label": ACTION_LABEL[a]} for a in card.actions]
        obj["fields"] = fields
        objects.append(obj)
        for rel in card.relationships:
            if rel["inverse"] or d.relationship_phase(CARDS, card, rel) > PHASE:
                continue
            if rel["name"] in old_rels:
                relationships.append(old_rels[rel["name"]])
                continue
            out = {"name": rel["name"]}
            if rel["type"] == "MANY_TO_MANY":
                out["type"] = "MANY_TO_MANY"
            out.update({"label": relationship_label(CARDS, plural, rel), "inverseLabel": plural[name], "source": name,
                        "target": rel["target"]})
            if rel["type"] == "MANY_TO_ONE":
                out["fieldName"] = rel["field"]
                if rel["required"]:
                    out["required"] = True
            relationships.append(out)
    catalogs = d.catalogs()
    enums = {key: existing["enums"].get(key, catalogs[key]) for key in sorted(used)}
    return {"enums": enums, "objects": objects, "relationships": relationships}


def dump(model):
    """The hand layout of model.json: one enum, field or relationship per line."""
    line = lambda value: json.dumps(value, ensure_ascii=False)  # noqa: E731
    out = ["{", '  "enums": {']
    keys = list(model["enums"])
    for i, key in enumerate(keys):
        out.append(f"    {line(key)}: {line(model['enums'][key])}{',' if i < len(keys) - 1 else ''}")
    out.append("  },")
    out.append('  "objects": [')
    for i, obj in enumerate(model["objects"]):
        out.append("    {")
        for k in [k for k in obj if k != "fields"]:
            out.append(f"      {line(k)}: {line(obj[k])},")
        out.append('      "fields": [')
        for j, field in enumerate(obj["fields"]):
            out.append(f"        {line(field)}{',' if j < len(obj['fields']) - 1 else ''}")
        out.append("      ]")
        out.append("    }" + ("," if i < len(model["objects"]) - 1 else ""))
    out.append("  ],")
    out.append('  "relationships": [')
    for i, rel in enumerate(model["relationships"]):
        out.append(f"    {line(rel)}{',' if i < len(model['relationships']) - 1 else ''}")
    out.append("  ]")
    out.append("}")
    return "\n".join(out) + "\n"


CARDS = d.cards()

if __name__ == "__main__":
    sys.stdout.write(dump(build()))
```

```python
#!/usr/bin/env python3
"""One-shot generator of model/roles.json for phase F4 (plan 4.1, Tarea 3).

Run from the repository root, after model/model.json has the F4 objects:
python3 <this file> > model/roles.f4.json && mv model/roles.f4.json model/roles.json
Keeps the names, labels and descriptions of roles.json (but the roles whose work changes in F4), gives each
role the grants of security.md §7.2 to §7.8 for the objects of model.json, from the later of the role's phase and the
object's (§7.1), and rebuilds restrictedFields from §7.9 for the objects of model.json. Stdlib only.
"""
import json
import os
import sys

sys.path.insert(0, os.path.join(os.getcwd(), "model"))
import design_docs as d  # noqa: E402

PHASE = "F4"

# the descriptions said "Recibe permisos desde F4."; from F4 on they say what the role does. APPROVER also resolves the
# grievances of high severity (RN-GRV-002)
DESCRIPTION = {
    "GRIEVANCE_MANAGER": "Atiende las quejas, consultas y solicitudes; lee las confidenciales (READ_CONFIDENTIAL).",
    "SOCIAL_RISK_MANAGER": "Lleva la matriz de riesgos, los incidentes, las señales y las reglas, y confirma alertas.",
    "APPROVER": "Aprueba compromisos y resuelve quejas graves con la acción declarada APPROVE, sin editarlos.",
}


def build():
    with open("model/roles.json", encoding="utf-8") as f:
        current = json.load(f)
    with open("model/model.json", encoding="utf-8") as f:
        model = json.load(f)
    phases, _ = d.role_phases()
    cards = d.cards()
    matrix = d.matrix()
    names = [o["name"] for o in model["objects"]]
    for role in current["roles"]:
        name = role["name"]
        if name in DESCRIPTION:
            role["description"] = DESCRIPTION[name]
        if name == "AUDITOR":
            continue
        grants = {}
        for obj in names:
            if max(phases[name], cards[obj].phase) > PHASE:
                continue
            cell = matrix[obj][name]
            if cell:
                grants[obj] = cell
        role["permisos"] = grants
    restricted = []
    for obj, field, readers in d.restricted_fields():
        if obj not in names:
            continue
        readers = [r for r in readers if r in phases]
        same = next((e for e in restricted if e["object"] == obj and e["readers"] == readers), None)
        if same:
            same["fields"].append(field)
        else:
            restricted.append({"object": obj, "fields": [field], "readers": readers})
    current["restrictedFields"] = restricted
    return current


def dump(roles):
    line = lambda value: json.dumps(value, ensure_ascii=False)  # noqa: E731
    out = ["{", f'  "mappedToAdmin": {line(roles["mappedToAdmin"])},', '  "roles": [']
    for i, role in enumerate(roles["roles"]):
        out.append("    {")
        out.append(f'      "name": {line(role["name"])},')
        out.append(f'      "label": {line(role["label"])},')
        out.append(f'      "description": {line(role["description"])},')
        if role["permisos"]:
            out.append('      "permisos": {')
            items = list(role["permisos"].items())
            for j, (obj, grants) in enumerate(items):
                out.append(f"        {line(obj)}: {line(grants)}{',' if j < len(items) - 1 else ''}")
            out.append("      }")
        else:
            out.append('      "permisos": {}')
        out.append("    }" + ("," if i < len(roles["roles"]) - 1 else ""))
    out.append("  ],")
    out.append('  "restrictedFields": [')
    for i, entry in enumerate(roles["restrictedFields"]):
        out.append(f"    {line(entry)}{',' if i < len(roles['restrictedFields']) - 1 else ''}")
    out.append("  ]")
    out.append("}")
    return "\n".join(out) + "\n"


if __name__ == "__main__":
    sys.stdout.write(dump(build()))
```

```kotlin
    // los estados de las ejecuciones terminadas de `name` para el registro, de la más nueva a la más vieja, cuando son al
    // menos `count`: una que no cumple sus condiciones queda SKIPPED, y también cuenta
    private fun awaitRuns(
        objectName: String,
        name: String,
        recordId: String,
        count: Int,
        seconds: Long = 30
    ): List<String> {
        val deadline = System.nanoTime() + seconds * 1_000_000_000
        while (System.nanoTime() < deadline) {
            val statuses =
                tree(send("GET", "/api/objects/$objectName/automations/$name/runs?limit=50", null, HttpStatus.OK))
                    .values()
                    .filter { it["recordId"]?.asString() == recordId }
                    .map { it["status"].asString() }
            if (statuses.size >= count && statuses.none { it == "PENDING" || it == "RUNNING" }) return statuses
            Thread.sleep(250)
        }
        throw AssertionError("$name no llegó a $count ejecuciones terminadas en $seconds s para $objectName $recordId")
    }
```
