[abstract]
.Presentación
--
Esta referencia reúne lo que conviene consultar y no leer de corrido: los _endpoints_ de la API, los 90 objetos del
modelo con sus campos, la matriz de permisos de los 15 roles, los 19 workflows, las automatizaciones, los 53
indicadores y el glosario.

Las secciones marcadas como _generadas_ se producen con `docs/manuals/scripts/generate-reference.py` a partir de
`model/` (la fuente de verdad del modelo), así que no pueden divergir de él: si el modelo cambia, se regeneran con
`docs/manuals/scripts/build-docs.sh references`. El resto se contrastó con el código de la versión {product-version}.
--
