.Presentación
--
Este manual permite a un ingeniero que no conoce SGSPE comprender cómo está construido, instalarlo, configurarlo,
operarlo, actualizarlo y recuperarlo ante una incidencia. Describe el sistema tal como está en el código de la versión
{product-version}: cada afirmación remite al archivo que la respalda, y lo que no pudo verificarse se señala como
tal.

*Público:* administradores técnicos, operadores de plataforma, DBA y desarrolladores. El uso funcional del portal se
explica en el xref:../user/manual-usuario.adoc[Manual de usuario]; la administración funcional (usuarios, roles,
modelo), en el xref:../administrator/manual-administrador.adoc[Manual del administrador]; el detalle de objetos,
permisos, workflows y API, en la xref:../reference/referencia-tecnica.adoc[Referencia técnica].
--
