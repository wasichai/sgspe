.Presentación
--
Este manual explica cómo usar el portal de SGSPE para el trabajo diario del equipo social de un proyecto extractivo:
registrar y consultar grupos de interés, interacciones, compromisos, quejas, consultas y solicitudes, riesgos, aportes
sociales, evidencias y tareas, y obtener reportes y entregables.

Cada procedimiento indica qué se consigue, qué se necesita, los pasos, qué debe mostrar el sistema y cómo comprobar que
terminó bien. Las imágenes son capturas de la aplicación real, tomadas con el conjunto de datos *ficticio* de
demostración (proyecto «DEMO-T1 · Proyecto Wayra Ejemplo»): ningún nombre, lugar o documento corresponde a personas o
casos reales.

Lo que puede hacer cada persona depende de su rol y de los proyectos a los que está asignada: si un botón o una sección
de este manual no aparece en su pantalla, consulte <<usr-roles>>.
--
